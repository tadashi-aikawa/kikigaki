---
title: データの行き先
description: 会議の内容が残る場所、AIエージェントへ渡る内容、AIエージェントが書き換えられる範囲
---

音声や書き起こしがどこに残り、AIエージェント(Claude Code か Codex のCLI)へ何が渡るかを説明します。
業務で使う前に、保存先・送信先・AIエージェントが書ける範囲を確かめられます。

## 要点

- 音声と書き起こしは、Macの中で処理・保存します
- 会議の内容が外へ出るのは、AIエージェントの参加を設定して送信したときだけです
- 利用状況や不具合の情報は送りません
- AIエージェントの参加を使わなければ、会議の内容は外へ出ません

| 情報 | 端末内に保存 | AIサービスへ送信 | そのほかの外部へ送信 |
| --- | --- | --- | --- |
| マイクとシステム音声 | 設定時のみ | しない | しない |
| 書き起こし | する | AIエージェントの参加時のみ | しない |
| 手入力と添付画像 | する | AIエージェントの参加時のみ | しない |
| 議事録 | する | AIエージェントの参加時のみ | しない |
| 利用状況や不具合の情報 | しない | しない | しない |

- 設定時のみ: `saveRecording = true` のときだけ、録音をWAVで残します
- AIエージェントの参加時のみ: `[[ai]]` を設定し、手動か自動で送信したときだけ、自分のMacで動くAIエージェントを経由して各サービスへ送ります
- AIエージェントへ送った内容の扱いは、使うサービスの契約と設定に従います

## 端末内で処理するもの

- 文字起こし: Macの中のApple Speechで処理します
- 話者判別: ダウンロードした話者判別モデル(Nemotron 3 Diarization)をMacの中で使います
- システム音声: Macの中でマイクの音と混ぜます
    - 用途: 混ぜた音を書き起こしと話者判別に使います
    - 保存: `saveRecording = true` のときだけ残します

## 端末内に保存するもの

### 保存先 `outputDir` の中

既定は `~/Documents/KIKIGAKI` です。

| 場所 | 中身 | 作られるとき |
| --- | --- | --- |
| `<会議名>.md` | 書き起こしとAIエージェントとのやりとり | 録音を止めたとき |
| `<会議名>.wav` | 録音 | `saveRecording = true` のとき |
| `<会議名>.levels.json` | 発話ごとの音量の記録 | `measureAudioLevels = true` のとき |
| `<会議名>.attachments/` | 手入力に貼った画像 | 画像を投稿したとき |
| `.kikigaki-context/<会議ID>/` | 固定した会話のファイルと、AIエージェントとのやりとりの記録 | 会話をコピーしたときと、AIエージェントへ送ったとき |

- 新しく保存する書き起こし・録音・音量記録・添付画像は0600で作ります
    - 意味: 持ち主だけが読み書きできます
- 新しく作る保存先フォルダと添付画像のフォルダは0700で作ります
- 既存の保存先フォルダと既存ファイルの権限は一括変更しません
    - 更新: 書き起こしと音量記録を保存し直すと、そのファイルは0600になります
- 同じユーザーのアプリや同期・共有サービスによるアクセスは制限しません

`.kikigaki-context/<会議ID>/` には次のものが入ります。

- コピー・送信した時点の会話のファイル
    - 中身: 話者名付きの書き起こしと手入力が、1発話1行で入ります
- `ai/` の中の、AIエージェントへの依頼、返事、確認質問、状態、議事録の場所の記録
- AIエージェントの返事を確かめるためのトークン
- Claude Codeに渡す、この会議専用の設定ファイル

このフォルダと中のファイルは、持ち主だけが読める権限で作ります。
フォルダは0700、ファイルは0600です。
会議が終わっても自動では消しません。
会議のMarkdownを消しても、このフォルダの中身は残ります。

会議の記録を完全に消すときは、ここも確認してください。

### そのほかの場所

| 場所 | 中身 |
| --- | --- |
| `~/Library/Application Support/FluidAudio/Models/nemotron-3-diarization` | 話者判別モデル |
| `~/Library/Application Support/KIKIGAKI/ai-roots.json` | AIエージェントの返事を待つ会議の保存先の一覧 |
| `~/Library/Application Support/KIKIGAKI/ai-work/` | AIエージェントを起動するときの既定の作業ディレクトリ |
| `~/Library/Caches/kikigaki/avatars/` | URLで指定したアバター画像のキャッシュ |
| アプリの環境設定 | 開始シートの前回の選択、最近表示した議事録10件の場所、議事録ペインの幅 |
| 議事録のファイル | 自分かAIエージェントが決めた場所 |

## AIエージェントの参加時に渡るもの

`[[ai]]` を設定し、送信したときだけ、次の内容がAIエージェントへ渡ります。

送信する場面は次の5つです。

- 手動実行
- 確認質問への返答
- 再送
- 自動送信
- 録音停止時の最後の1回

### 送信の文に含むもの

- 宛名と、設定の `prompt` の追加指示
- 問い欄に書いた文
    - 例外: 空欄なら、会話の末尾で声にした問いを使います
- 自動送信なら、そのプロンプト
- まだ確定していない末尾の文字
- 会議のID
- 会話ファイルの場所と、読む行の範囲
- 議事録の場所
- 作業の許可の有無
- 返送用のトークン

### AIエージェントが読むもの

- 会話ファイルの、指定された範囲
    - 範囲: 1回目は全体、2回目以降は前回から変わった部分です
    - 中身: 話者名付きの書き起こしと手入力の本文を含みます
    - 画像: ファイルの場所を含みます。AIエージェントがファイルを読むと、画像の中身も渡ります
- 議事録の場所を渡していれば、その議事録のファイル
- 作業を許可していれば、依頼に必要な範囲で、CLIの権限が及ぶほかのファイルやURL

KIKIGAKIが音声のファイルをAIエージェントへ渡すことはありません。

### 送られる先

これらは、AIエージェントが接続するAIサービスへ送られます。
どのサービスと契約で処理されるかは、それぞれのCLIの設定とアカウントで決まります。

業務で使う場合は、会議の内容をそのサービスへ渡してよいかを先に確かめてください。

### AIエージェントが書き換えられるもの

- Codexには、保存先 `outputDir` への書き込みを許可して起動します
    - 理由: 議事録をそこへ書けるようにするためです
    - 範囲: 全会議のMarkdownと `.kikigaki-context/` の中身を、AIエージェントから書き換えられます
    - 制約: 会議のMarkdownを直接編集しないことはSkillの決まりです。権限では防いでいません
- それ以外の場所への書き込みは、CLIの権限設定と承認に従います
- KIKIGAKIは、CodexとClaude Codeの設定ファイルを書き換えません
    - 動き: 初回の信頼確認を承認すると、CLI自身がその記録を自分の設定に残します

### 使わないとき

`[[ai]]` を書かなければ、AIエージェントの機能は動きません。
「会話をコピー」はクリップボードへ書くだけで、どこへも送りません。
貼り付けた先のAIエージェントへは、自分で渡すことになります。

## そのほかの通信

| 接続先 | いつ | 送るもの |
| --- | --- | --- |
| Hugging Face | 話者判別モデルの初回の取得 | モデルの取得要求だけ。音声や文字起こしは送らない |
| Apple | Apple Speechの日本語アセットが未導入のとき | アセットの取得要求だけ |
| アバターの配信元 | 設定でアバターにURLを書いたとき | 画像の取得要求 |
| 議事録の画像の配信元 | 議事録に外部の画像URLが書かれているとき | 画像の取得要求 |

- 手入力のURLは、クリックしたときに既定のブラウザで開きます
    - 通信: KIKIGAKIが先にページを読み込むことはありません
