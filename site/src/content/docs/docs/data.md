KIKIGAKIが扱う情報の保存先と送信先をまとめます。
業務で使えるかを判断するときの材料にしてください。

## 要点

- 音声と文字起こしは端末内で処理し、保存先も端末内です
- 外へ出るのは、AI参加を自分で設定して送信した内容だけです
- 利用状況や不具合の情報は送りません
- AI参加を使わなければ、会議の内容は外へ出ません

| 情報 | 端末内に保存 | AIサービスへ送信 | そのほかの外部へ送信 |
| --- | --- | --- | --- |
| マイクとシステム音声 | 設定時のみ | しない | しない |
| 書き起こし | する | AI参加時のみ | しない |
| 手入力と添付画像 | する | AI参加時のみ | しない |
| 議事録 | する | AI参加時のみ | しない |
| 利用状況や不具合の情報 | しない | しない | しない |

- 設定時のみ: `saveRecording = true` のときだけ、録音をWAVで残します
- AI参加時のみ: `[[ai]]` を設定し、手動か自動で送信したときだけ、自分のMacで動くCodex・Claude Codeを経由して各サービスへ送ります
- AIへ送った内容の扱いは、使うサービスの契約と設定に従います

## 端末内で処理するもの

- 文字起こし: macOSのApple Speechで、端末内で処理します
- 話者判別: 端末に取得したモデルで処理します
- システム音声の取り込み: Macの中でマイクの音と混ぜます。混ぜた音は文字起こしと話者判別に使い、`saveRecording = true` でなければ残しません

## 端末内に保存するもの

### 保存先 `outputDir` の中

既定は `~/Documents/KIKIGAKI` です。

| 場所 | 中身 | 作られるとき |
| --- | --- | --- |
| `<会議名>.md` | 書き起こしとAIとのやりとり | 録音を止めたとき |
| `<会議名>.wav` | 録音 | `saveRecording = true` のとき |
| `<会議名>.levels.json` | 発話ごとの音量の記録 | `measureAudioLevels = true` のとき |
| `<会議名>.attachments/` | 手入力に貼った画像 | 画像を投稿したとき |
| `.kikigaki-context/<会議ID>/` | 固定した会話のファイルと、AIとのやりとりの記録 | 会話をコピーしたときと、AIへ送ったとき |

`.kikigaki-context/<会議ID>/` には次のものが入ります。

- 会話をコピー・送信するたびに固定した会話のファイル。話者名付きの書き起こしと手入力を、1発話1行で書きます
- `ai/` の中の、AIへの依頼、返事、確認質問、状態、議事録の場所の記録
- AIの返送を確かめるためのトークン
- Claude Codeに渡す、この会議専用の設定ファイル

このフォルダは0700、中のファイルは0600の権限で作ります。
会議が終わっても自動では消しません。
会議のMarkdownを消しても、このフォルダの中身は残ります。会議の記録を完全に消すときは、ここも確認してください。

### そのほかの場所

| 場所 | 中身 |
| --- | --- |
| `~/Library/Application Support/FluidAudio/Models/nemotron-3-diarization` | 話者判別モデル |
| `~/Library/Application Support/KIKIGAKI/ai-roots.json` | 返事を待っているAI会議の保存先の一覧 |
| `~/Library/Application Support/KIKIGAKI/ai-work/` | AIを起動するときの既定の作業ディレクトリ |
| `~/Library/Caches/kikigaki/avatars/` | URLで指定したアバター画像のキャッシュ |
| アプリの環境設定 | 開始シートの前回の選択、最近表示した議事録10件の場所、議事録ペインの幅 |
| 議事録のファイル | 自分かAIが決めた場所 |

## AI参加時に渡るもの

`[[ai]]` を設定し、送信したときだけ、次のものがAIへ渡ります。
送信するのは、手動実行・確認質問への返答・再送・自動送信・録音停止時の最後の1回です。

### 送信の文に含むもの

- 宛名と、設定の `prompt` の追加指示
- 問い欄に書いた文。空欄なら会話の末尾の声の問い
- 自動送信なら、そのプロンプト
- まだ確定していない末尾の文字
- 会議のID、会話のファイルの場所と読む行の範囲、議事録の場所、作業の許可の有無、返送用のトークン

### AIが読むもの

- 会話のファイルの、指定された範囲。1回目は全体、2回目以降は前回から変わった部分です
    - 話者名付きの書き起こしと手入力の本文を含みます
    - 添付画像はファイルの場所を含みます。AIがそのファイルを読めば、画像の中身も渡ります
- 議事録の場所を渡していれば、その議事録のファイル
- 作業を許可していれば、依頼に必要な範囲で、CLIの権限が及ぶほかのファイルやURL

KIKIGAKIが音声のファイルをAIへ渡すことはありません。

### 送られる先

これらは、CodexやClaude Codeが接続するAIサービスへ送られます。
どのサービスと契約で処理されるかは、それぞれのCLIの設定とアカウントで決まります。

業務で使う場合は、会議の内容をそのサービスへ渡してよいかを先に確かめてください。

### AIが書き換えられるもの

- Codexは、保存先 `outputDir` への書き込みを許可して起動します。議事録をそこへ書けるようにするためです
    - そのため、全会議のMarkdownと `.kikigaki-context/` の中身を、AIから書き換えられます
    - 会議のMarkdownを直接編集しないことはSkillの決まりで、権限では防いでいません
- それ以外の場所への書き込みは、CLIの権限設定と承認に従います
- KIKIGAKIは、CodexとClaude Codeの設定ファイルを書き換えません。初回の信頼確認を承認したときは、CLI自身がその記録を自分の設定に残します

### 使わないとき

`[[ai]]` を書かなければ、AIの機能は動きません。
「会話をコピー」はクリップボードへ書くだけで、どこへも送りません。貼り付けた先のAIへは、自分で渡すことになります。

## そのほかの通信

| 接続先 | いつ | 送るもの |
| --- | --- | --- |
| Hugging Face | 話者判別モデルの初回の取得 | モデルの取得要求だけ。音声や文字起こしは送らない |
| Apple | Apple Speechの日本語アセットが未導入のとき | アセットの取得要求だけ |
| アバターの配信元 | 設定でアバターにURLを書いたとき | 画像の取得要求 |
| 議事録の画像の配信元 | 議事録に外部の画像URLが書かれているとき | 画像の取得要求 |

- 手入力のURLは、クリックしたときに既定のブラウザで開くだけです。KIKIGAKIが先に取得することはありません
