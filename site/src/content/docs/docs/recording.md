録音を始めてから、書き起こしを読み、話者を直し、保存されたファイルを使うまでの操作をまとめます。

## 録音を始める

メニューバーのKIKIGAKIのロゴから「開く」を選ぶと、書き起こしウィンドウが開きます。
「録音を開始」を押すと、その会議だけの指定を決めるシートが出ます。
メニューバーのメニューの「録音を開始」からも同じシートが出ます。

| 行 | 決めるもの | 既定値 |
| --- | --- | --- |
| システム音声 | 「自動」「取り込む」「取り込まない」 | 前回の選択。初回は自動 |
| 話者判別 | 「区別する(最大8人)」「区別しない」 | 前回の選択 |
| 小音量除外 | 小さな声の発話を除外するか | 前回の選択 |
| 議事録 | 右のペインに表示する議事録のファイル | 空欄 |
| 自動送信 | AIへの定期的な送信 | 設定の `autoStart` の宛先。無ければ「送らない」 |

- 「開始」を押すか、⏎か⌘⏎で録音が始まります
    - 例外: プロンプト欄に入力中の⏎は改行になります
- Escか「取消」で閉じると、何も始まりません
- シートで決めた値はその会議だけに効きます。設定ファイルへは書き戻しません
- 自動送信の行は、設定でAI参加を有効にしたときだけ出ます。[AIを会議に参加させる](../ai-participant/) を参照してください
- システム音声は [オンライン会議で相手の声を取り込む](../online-meetings/)、議事録は [議事録とボード](../minutes-and-board/) で説明します

### 話者判別を使わない会議

1人で話すときや、話者を区別しなくてよい会議では「区別しない」を選びます。

- 音声の行はすべて共通の「発言」という名前で表示します
- 話者の固定を待たないので、文字が確定した時点で通常の濃さになります
- 1秒以上の間や、句点・疑問符・感嘆符の後で行を分けます。30秒を超えて話し続けた行も途中で分けます
- 話者判別は録音を始めた後には切り替えられません

## 書き起こしを読む

各行は、アバター・話者名・時刻・本文で表示します。

```
[アバター]  田中  14:32:05
            では次の議題、来期の予算配分に移ります。
```

- 時刻は実際の時刻です。一時停止していた時間も反映します
- 時刻にマウスを載せると、会議の開始からの経過時間が出ます
- 話者は「話者A」〜「話者H」の名前で始まります。最大8人です
- 話者判別は推定です。必要に応じて書き起こしと話者を確認してください

### 半透明の行

録音中の行は、文字や話者がまだ変わる可能性があるうちは半透明で表示します。
変わらなくなると通常の濃さになります。

- 文字は先に速報を出し、精度の高い認識結果へ後から静かに差し替えます
- 話者は、後に続く発言を待ってから固定します。そのため最後の発言は、黙っていても半透明のまま残ることがあります
- 通常の濃さは、認識が正しいことの保証ではありません
- 半透明の行も、コピーやAIへの送信には含まれます

### 「聞き取り中…」の行

いま認識している途中の文字は、最後に「聞き取り中…」という名前の行で表示します。
確定すると、話者付きの通常の行に変わります。
この行はコピーやAIへの送信には含めません。

### 停止したとき

停止すると、会議全体の音声で話者を判定し直した最終結果に切り替えてから保存します。
録音中の表示と比べて、話者や行の区切りが変わることがあります。

### そのほかの操作

- 一時停止・再開: ヘッダーのボタンかメニューバーのメニューから。一時停止中は音声を取り込みません
- 検索: ⌘F
- 最新の発言へ戻る: 「最新の発言」のボタンで末尾へ戻ります。末尾を表示している間は、新しい発言に合わせて自動でスクロールします
- 最前面に固定: フッターのピンボタンで、ほかのアプリより手前に残します。アプリを再起動すると解除されます

## 話者名を変える

話者名かアバターをクリックすると、名前を選ぶ画面が開きます。

- 候補の一覧: 設定ファイルの `[[speakers]]` に書いた名前とアバターです。クリックで反映します
- 自由入力: 名前を書いてReturnで反映します
- 「既定に戻す」: 「話者A」などの既定名へ戻します

変更はその話者の全部の行に効きます。1行だけを別の話者へ付け替えることはできません。
停止後に変えた場合は、保存したMarkdownも書き直します。
新しい録音を始めると、名前は既定に戻ります。

話者の候補は次のように設定します。

```toml
[[speakers]]
name = "田中"
avatar = "~/Pictures/avatars/tanaka.png"

[[speakers]]
name = "佐藤"
avatar = "https://example.com/sato.webp"
```

## 話者を統合する

同じ人が「話者A」と「話者C」のように2人に分かれたときは、ウィンドウ上部の人型のボタンから統合します。

1. 人型のボタンを押します
2. 分かれた側の話者で、統合先を選びます。例: 話者Cの統合先を話者Aにする
3. 元に戻すときは「統合しない」を選びます

- 統合は話者ごとに効きます。発言ごとに分け直すことはできません
- 録音中・一時停止中・停止後のいつでも変えられます。停止後は保存したMarkdownも書き直します
- AIへ既に送った範囲の話者を変えた場合は、次のAIへの送信で訂正として伝わります
- 人型のボタンには、この会議で検出した話者の数が出ます。統合しても数は減りません

## 小さな声を除外する

隣の会議の声のように、離れた場所の小さな声を書き起こしから外せます。

- 開始シートの「小音量除外」か、人型のボタンの画面でオン・オフを切り替えます
- しきい値は人型のボタンの画面で、−80〜−20 dBFSの間で調整します。オンにした直後は−45 dBFSです
- 入力の音量で判定するので、マイクや入力の音量を変えたら調整し直してください
- 除外した行は画面に半透明で残り、「小音量のため除外」と注記します。オフにするか、しきい値を下げると元に戻ります
- 除外した行は、コピー・AIへの送信・Markdownの本文から外します。Markdownでは末尾の「小音量で除外した発話」に全文を残します

## 手入力と画像

会議中に共有されたURLや補足を、発話と同じ流れへ書き込めます。

- 本文とフッターの間の入力欄に書き、⌘Enterで投稿します。Enterは改行です
- 投稿した行は「手入力」という名前で、発話と時刻順に並びます
- URLはクリックすると既定のブラウザで開きます
- 書き込めるのは録音中と一時停止中だけです
- 投稿しても、AIへの送信は始まりません

### 画像を添付する

入力欄で⌘Vを押すと、クリップボードの画像か、コピーした画像ファイルを添付します。

- 複数枚の添付と、画像だけの投稿ができます
- 1枚10 MiB・4,000万画素までです
- 画像は保存先の `<会議名>.attachments/` へ保存し、Markdownに埋め込みます
- 投稿した画像のサムネイルをクリックすると、既定のアプリで開きます
- AIへ送るときは、画像の中身を文字にせず、ファイルの場所を渡します

## 保存されるファイル

停止すると、保存先へ1会議1ファイルのMarkdownを書きます。
保存先の既定は `~/Documents/KIKIGAKI` で、設定の `outputDir` で変えられます。

```
~/Documents/KIKIGAKI/
├── 2026-09-05_1240.md              会議のMarkdown
├── 2026-09-05_1240.wav             録音。saveRecording = true のときだけ
├── 2026-09-05_1240.levels.json     音量の記録。measureAudioLevels = true のときだけ
├── 2026-09-05_1240.attachments/    手入力に貼った画像
└── .kikigaki-context/              コピーやAI送信で固定した会話と、AIとのやりとりの記録
```

- ファイル名は録音を始めた日時です。同じ分に録音を始め直したときは `_2`、`_3` を付けます
- 保存先はメニューバーのメニューの「保存先を開く」で開けます
- `.kikigaki-context/` の中身は [データの行き先](../data/) で説明します

Markdownは次の形です。

```markdown
# KIKIGAKI 2026-09-05 12:40

- 開始: 2026-09-05 12:40
- 長さ: 32:15
- 話者: A=田中, B=佐藤

## 書き起こし

- [12:40:05] 田中: では始めます。
- [12:40:12] 佐藤: よろしくお願いします。
- [12:41:30] 手入力: https://example.com/meeting
```

- AIとやりとりした会議には、末尾に `## AIとのやりとり` が付きます
- 小さな声を除外した会議には、`## 小音量で除外した発話` が付きます

### Markdownを手で編集するとき

会議のMarkdownはKIKIGAKIが生成するファイルです。
停止後に話者名を変えたときや、AIの返事が届いたときに、KIKIGAKIが書き直します。
手で編集した内容はそのときに上書きされるので、残したいメモは別のファイルに書いてください。

### 前の会議

保存が終わると、ボタンが「新しい録音」に変わります。
話者名の変更や統合ができるのは、表示している会議だけです。
新しい録音を始めると、前の会議は画面から操作できなくなります。
