会議やひとりの声を録って、話した言葉をMarkdownに残せます。
録音の始め方から、画面の読み方と話者の直し方までを説明します。

## 録音を始める

メニューバーのKIKIGAKIのロゴから「開く」を選ぶと、書き起こしウィンドウが開きます。
「録音を開始」を押すと、その会議の設定を選ぶシートが出ます。
メニューバーのメニューの「録音を開始」からも同じシートが出ます。

- 開始シートは、書き起こしウィンドウに付いて出ます。
  - 高さ: 候補や「指定しない」、宛先を選び直しても、開いている間は高さが変わりません。
  - 自動送信: 「送らない」では詳細欄が薄くなり、操作できなくなります。
  - スクロール: 画面に収まらない場合は、中身をスクロールして選べます。

| 行 | 決めるもの | 既定値 |
| --- | --- | --- |
| システム音声 | 「自動」「取り込む」「取り込まない」 | 前回の選択。初回は自動 |
| マイク | いま使うマイクの名前。表示のみ | Macの既定入力 |
| 話者判別 | 「区別する(最大8人)」「区別しない」 | 前回の選択 |
| 小音量除外 | 小さな声の発話を除外するか | 前回の選択 |
| 議事録 | 右のペインに表示する議事録のファイル | 空欄 |
| 自動送信 | AIエージェント(Claude Code か Codex のCLI)への定期的な送信 | 設定の `autoStart` の宛先。無ければ「送らない」 |
| 手動送信 | 手動実行と声の合図で送る宛先 | 前回の開始シートで選んだ宛先。初回は設定の1つ目 |

- 「開始」を押すか、⏎か⌘⏎で録音が始まります
    - 例外: プロンプト欄に入力中の⏎は改行になります
- Escか「取消」、書き起こしウィンドウのシート外クリックで閉じると、何も始まりません
    - 例外: 「ファイルを選ぶ…」のパネルが開いている間は、外側クリックで閉じません
- シートで決めた値はその会議だけに効きます。設定ファイルへは書き戻しません
- 自動送信と手動送信の行は、設定でAIエージェントの参加を有効にしたときだけ出ます。
    - 詳細: [AIエージェントを会議に参加させる](../ai-participant/)
- 手動送信は宛先だけを選びます。
    - 選択: 全宛先と「指定しない」から選べます。覚えていた宛先が設定から消えた場合は1つ目へ戻ります。
    - 指示: 毎回付く指示がある宛先では、宛先メニューの下に「＋ 毎回付く指示あり」が出ます。
    - 中身: マウスを載せると全文を読めます。宛先を選び直すと表示も切り替わります。
    - 会議中: 手動実行の送信に成功すると、その宛先へ切り替わります。
    - 記憶: 次の開始シートには、開始時に選んだ宛先が出ます。
- 詳細: [オンライン会議で使う](../online-meetings/)
- 詳細: [議事録とボード](../minutes-and-board/)

### 録音中にマイクをつなぎ替える

開始シートの「マイク」には、Macの既定入力の名前が出ます。
シートを開いている間につなぎ替えると、表示も変わります。

- マイクだけで録音しているときは、新しい既定マイクへ自動で乗り換えて録音を続けます。
  - 途切れた間: 無音として残します。
  - 表示: 書き起こしに `HH:mm マイクを <装置名> へ切替` が出ます。この行は保存するMarkdownやAIへ渡す会話には含めません。
- 再接続できないときは、ヘッダーに理由が出ます。
  - 復帰: 再接続を試し、音声が戻れば続けます。
- システム音声も取り込む録音では、取り込みが続けられなくなるとマイクだけへ切り替わります。
  - 表示: ヘッダーに理由が出ます。

### 次の会議を予約する

端末から、次の会議の議事録とAIエージェントの宛先を予約できます。

```bash
kikigaki-cli next add --minutes ~/work/minutes/定例.md --at 14:00 --ai 議事録 --manual スライド
```

- 開始シートの最上段に候補が出ます。
  - 操作: 先頭が選ばれた状態で、⏎で開始できます。
  - 選択: 別の候補は、丸・題・宛先やファイル名を含む行全体をクリックして選べます。
- 候補の行にマウスを乗せると、右端に×が出ます。
  - 操作: ×を押すと、その予約を削除できます。議事録のファイルは残ります。
  - 選択: 選択中の予約を消すと、残りの先頭を選び直します。残りが無ければ「指定しない」になります。
- 「指定しない」で、議事録を空欄に戻せます。
  - 自動宛先: 設定の `autoStart` の宛先へ戻ります。無ければ「送らない」になります。
  - 手動宛先: 前回の開始シートで選んだ宛先へ戻ります。
- `--manual` はその予約の手動宛先を指定します。
  - 省略時: 前回の宛先を使います。設定に無い宛先も前回の宛先へ戻ります。
  - 表示: 候補の2段目には自動と手動の宛先が並びます。設定に無い宛先は金色になります。
- 候補は時刻順に3件まで出ます。
- 選んで開始した予約1件だけが消えます。
  - 保持: 同じ議事録を指す別の予約は残ります。選んだ後に議事録欄を別のパスへ変えた場合も残ります。
  - 例外: 「指定しない」で開始した場合、取消、開始失敗では消えません。
- 登録から24時間経った予約は、次にシートを開いたときに消えます。
- 予約の時刻から自動で録音が始まることはありません。

詳細: [AIエージェントを会議に参加させる](../ai-participant/#次の会議を予約する)

### 話者判別を使わない会議

ひとりで話すときや、誰の発言かを分けなくてよい会議では「区別しない」を選びます。

- 音声の行はすべて共通の「発言」という名前で表示します
- 文字が確定した時点で、通常の濃さになります
    - 理由: 話者が決まるのを待たないためです
- 1秒以上の間や、句点・疑問符・感嘆符の後で行を分けます
- 30秒を超えて話し続けた行も、途中で分けます
- 話者判別は録音を始めた後には切り替えられません

## 書き起こしを読む

各行は、アバター・話者名・時刻・本文で表示します。

```
[アバター]  田中  14:32:05
            では次の議題、来期の予算配分に移ります。
```

- 時刻は実際の時刻です
    - 表示: 一時停止していた時間も反映します
- 時刻にマウスを載せると、会議の開始からの経過時間が出ます
- 話者は「話者A」〜「話者H」で始まります。最大8人です
- 誰の声かは推定です
    - 操作: 必要に応じて、書き起こしと話者を確認してください

### 半透明の行

文字や話者がまだ変わるかもしれない行は、半透明で出ます。
決まると、通常の濃さになります。

- 文字は先に速報が出て、後から精度の高い結果に変わります
- 話者は、後に続く発言を待ってから決まります
    - 結果: 最後の発言は、黙っていても半透明のまま残ることがあります
- 通常の濃さは、認識が正しいことの保証ではありません
- 半透明の行も、コピーやAIエージェントへの送信には含まれます

### 「聞き取り中…」の行

まだ聞き取りの途中の文字は、末尾の「聞き取り中…」の行に出ます。
確定すると、話者付きの通常の行に変わります。
この行はコピーやAIエージェントへの送信には含めません。

### 停止したとき

停止すると、会議全体の音声で話者を判定し直します。
画面を最終結果に切り替えてから保存します。
録音中の表示と比べて、話者や行の区切りが変わることがあります。

### そのほかの操作

- 一時停止・再開: ウィンドウ上部のボタンか、メニューバーのメニューから操作します
    - 動き: 一時停止中は音声を取り込みません
- 検索: ⌘F
- 文字の大きさ: 「表示」メニューの「文字を大きく」⌘+、「文字を小さく」⌘-、「実際のサイズ」⌘0
    - 範囲: 発言・投稿後の手入力・AIの行と、議事録・ボード・目次の文字を80%〜200%の8段階で変えられます
    - 対象外: 手入力欄や録音操作など、操作者向けの文字の大きさは変わりません
    - 拡大: 日本語配列では⌘;、US配列では⌘=でも使えます
    - 記憶: 次の起動でも前回の大きさに戻ります。議事録や保存する文章には影響しません
- 最新の発言へ戻る: 「最新の発言」を押します
    - 動き: 末尾を表示している間は、新しい発言に合わせてスクロールします
- 最前面に固定: フッターのピンボタンを押します
    - 動き: ほかのアプリより手前に残ります。アプリを再起動すると解除されます

## 話者名を変える

話者名かアバターをクリックすると、名前を選ぶ画面が開きます。
上に入力欄、その下に候補の一覧があります。

AIが付けた名前では、入力欄の下に割り当ての根拠を全文表示します。
長い根拠は折り返して表示します。

- 候補から選ぶ: 一覧の名前をクリックするか、↑↓で選んでReturnを押します
- 名前を打つ: 打った文字を含む候補に絞り込まれます
    - 候補を選ばずにReturnを押すと、打った名前をそのまま使います
    - 漢字の名前は漢字で、アルファベットの名前はアルファベットで打ちます。読みでは探しません
- 「既定に戻す」: 「話者A」などの既定名へ戻します

候補には次の名前が出ます。

- 会議の参加者: 議事録の先頭に `participants` として書いた名前。「参加者」の印が付きます
- よく使う名前: 直近30回の会議で話者に付けた名前。よく使う順に並びます
- 設定の `[[speakers]]` に書いた名前

ほかの話者に付けた名前は薄く出て、選べません。

議事録には、参加者を次のように書きます。

```markdown
---
participants:
  - Bob
  - Tadashi Aikawa
---
```

`attendees` など別の名前で書いている場合は、設定の `participantsKey` でその名前を指定します。

変更はその話者のすべての行に効きます。
1行だけを別の話者へ付け替えることはできません。
停止後に変えた場合は、保存したMarkdownも書き直します。
新しい録音を始めると、名前は既定に戻ります。

設定の `[[speakers]]` は次のように書きます。
アバターを付けられるのは、ここに書いた名前だけです。

```toml
[[speakers]]
name = "田中"
avatar = "~/Pictures/avatars/tanaka.png"

[[speakers]]
name = "佐藤"
avatar = "https://example.com/sato.webp"
```

## 話者を統合する

同じ人が「話者A」と「話者C」のように2人に分かれたときは、ウィンドウ上部の人型のボタンから統合します。

1. 人型のボタンを押します
2. 分かれた側の話者で、統合先を選びます
    - 例: 話者Cの統合先を話者Aにする
3. 元に戻すときは「統合しない」を選びます

- 統合は、その話者のすべての発言に効きます
    - 制約: 発言ごとに分け直すことはできません
- 録音中・一時停止中・停止後のいつでも変えられます
    - 保存: 停止後は保存したMarkdownも書き直します
- AIエージェントへ既に送った範囲の話者を変えた場合は、次のAIエージェントへの送信で訂正として伝わります
- 人型のボタンには、この会議で見つかった話者の数が出ます
    - 表示: 統合しても数は減りません

## 小さな声を除外する

隣の会議の声のように、離れた場所の小さな声を書き起こしから外せます。

- 開始シートの「小音量除外」か、人型のボタンの画面でオン・オフを切り替えます
- しきい値は人型のボタンの画面で、−80〜−20 dBFSの間で調整します
    - 既定: −45 dBFSです
- マイクや入力の音量を変えたら、調整し直してください
    - 理由: 入力の音量で判定するためです
- 除外した行は半透明で残り、「小音量のため除外」と出ます
    - 操作: オフにするか、しきい値を下げると元に戻ります
- 除外した行は、コピー・AIエージェントへの送信・Markdownの本文から外します
    - 保存: Markdownの末尾の「小音量で除外した発話」に全文を残します

## 手入力と画像

会議中に共有されたURLや補足を、発話と同じ流れへ書き込めます。

- 本文とフッターの間の入力欄に書き、⌘Enterで投稿します
    - 操作: Enterは改行です
- 投稿した行は「手入力」という名前で、発話と時刻順に並びます
- URLはクリックすると既定のブラウザで開きます
- 書き込めるのは録音中と一時停止中だけです
- 投稿しても、AIエージェントへの送信は始まりません

### 画像を添付する

入力欄で⌘Vを押すと、クリップボードの画像か、コピーした画像ファイルを添付します。

- 複数枚を添付できます
- 画像だけでも投稿できます
- 1枚10 MiB・4,000万画素までです
- 画像は保存先の `<会議名>.attachments/` へ保存し、Markdownに埋め込みます
- 投稿した画像のサムネイルをクリックすると、既定のアプリで開きます
- AIエージェントへは、画像ファイルの場所を渡します
    - しくみ: 画像の中身を文字に変えるのではなく、AIエージェントがファイルを読める形で渡します

## 保存されるファイル

停止すると、会議ごとにMarkdownを1つ保存します。
保存先の既定は `~/Documents/KIKIGAKI` で、設定の `outputDir` で変えられます。

```
~/Documents/KIKIGAKI/
├── 2026-09-05_1240.md              会議のMarkdown
├── 2026-09-05_1240.wav             録音。saveRecording = true のときだけ
├── 2026-09-05_1240.levels.json     音量の記録。measureAudioLevels = true のときだけ
├── 2026-09-05_1240.attachments/    手入力に貼った画像
└── .kikigaki-context/              コピーやAIエージェントへの送信で固定した会話と、やりとりの記録
```

- ファイル名は録音を始めた日時です
    - 例外: 同じ分に録音を始め直したときは `_2`、`_3` を付けます
- 保存先はメニューバーのメニューの「保存先を開く」で開けます
- `.kikigaki-context/` の中身は [データの行き先](../data/) で説明します

Markdownは次の形です。

```markdown
# KIKIGAKI 2026-09-05 12:40

- 開始: 2026-09-05 12:40
- 長さ: 32:15
- 話者: A=田中, B=佐藤

## 書き起こし

- [12:40:05] 田中: では始めます。
- [12:40:12] 佐藤: よろしくお願いします。
- [12:41:30] 手入力: https://example.com/meeting
```

- AIエージェントとやりとりした会議には、末尾に `## AIとのやりとり` が付きます
- 小さな声を除外した会議には、`## 小音量で除外した発話` が付きます

### Markdownを手で編集するとき

会議のMarkdownはKIKIGAKIが書き出します。
停止後に話者名を変えたときや、AIエージェントの返事が届いたときに、KIKIGAKIが書き直します。
手で編集した内容も、そのときに上書きされます。

残したいメモは、別のファイルに書いてください。

### 前の会議

保存が終わると、ボタンが「新しい録音」に変わります。
話者名の変更や統合ができるのは、表示している会議だけです。
新しい録音を始めると、前の会議は画面から操作できなくなります。
