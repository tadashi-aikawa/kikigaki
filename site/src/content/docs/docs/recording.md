---

会議やひとりの声を録って、話した言葉をMarkdownに残せます。
録音の始め方から、画面の読み方と話者の直し方までを説明します。

## 録音を始める

1. メニューバーのKIKIGAKIのロゴから「開く」を選びます
2. 書き起こしウィンドウの「録音を開始」を押します
3. 開いたシートで、その会議の設定を確かめます
4. 「開始」か⏎で始めます

![システム音声、マイク、話者判別、小音量除外、議事録、自動送信、手動送信の行が並ぶ録音開始シート](/kikigaki/captures/start-sheet.webp)

| 行 | 決めるもの |
| --- | --- |
| システム音声 | オンライン会議の相手の声も取り込むか。詳細: [オンライン会議で使う](../online-meetings/) |
| マイク | いま使うマイク。Macの既定の入力が出ます |
| 画面 | 映している画面を記録するか。記録するならディスプレイを1枚選びます |
| 話者判別 | 話者を「区別する(最大8人)」か「区別しない」か |
| 小音量除外 | 離れた場所の小さな声を外すか。詳細: [小さな声を除外する](#小さな声を除外する) |
| 議事録 | 右のペインに表示する議事録。詳細: [議事録とボード](../minutes-and-board/) |
| 自動送信・手動送信 | AIエージェントへ送る宛先。詳細: [AIエージェントを会議に参加させる](../ai-participant/) |

ここで選んだ値は、その会議だけに効きます[^sheet]。

### 話者判別を使わない会議

ひとりで話すときや、誰の発言かを分けなくてよい会議では、話者判別で「区別しない」を選びます。
音声の行はすべて「発言」という名前で出て、話者が決まるのを待たずに確定します。

### 次の会議を予約する

端末から、次の会議の議事録とAIエージェントの宛先を予約しておけます。

```bash
kikigaki-cli next add --minutes ~/work/minutes/定例.md --at 14:00 --ai 議事録
```

次に開始シートを開くと、一番上に候補が出て、先頭が選ばれています。
そのまま⏎で始めると、その予約は消えます[^next]。

コマンドの書き方は [AIエージェントを会議に参加させる](../ai-participant/#次の会議を予約する) で説明します。

## 書き起こしを読む

話すと、話した言葉が話者付きで順に出ます。

![3人の会議の書き起こし。確定前の行は半透明で、最後に聞き取り中の行が出ている](/kikigaki/captures/speakers.webp)

- 時刻: 実際の時刻です。マウスを載せると、会議の開始からの経過時間が出ます
- 話者: 「話者A」〜「話者H」で始まります。誰の声かは推定なので、違っていたら [直します](#話者を直す)
- 半透明の行: 文字や話者がまだ変わるかもしれない行です。決まると通常の濃さになります
- 「聞き取り中…」の行: まだ聞き取りの途中の文字です

停止すると、会議全体の音声で話者を判定し直してから保存します。
録音中の表示と比べて、話者や行の区切りが変わることがあります。

## 話者を直す

話者の名前の変更と統合は、録音中も停止後もできます。
停止後に直すと、保存したMarkdownも書き直します。

:::caution
新しい録音を始めると、前の会議は直せなくなります。直すなら、その前に済ませてください。
:::

### 話者名を変える

1. 話者名かアバターをクリックします
2. 候補から選ぶか、名前を打ってReturnを押します

変更は、その話者のすべての行に効きます[^rename]。

候補には、議事録の先頭に `participants` として書いた参加者、直近の会議で付けた名前、設定の `[[speakers]]` に書いた名前が出ます。

```markdown
---
participants:
  - Bob
  - Tadashi Aikawa
---
```

アバターを付けたいときは、設定の `[[speakers]]` に書きます[^participants]。

```toml
[[speakers]]
name = "田中"
avatar = "~/Pictures/avatars/tanaka.png"
```

### 話者を統合する

同じ人が「話者A」と「話者C」のように2人に分かれたときは、まとめられます。

![話者Aと話者Cに分かれた同じ人の発言が、統合すると話者Aにまとまる図](/kikigaki/diagrams/speaker-merge.svg)

1. ウィンドウ上部の人型のボタンを押します
2. 分かれた側の話者(例: 話者C)で、統合先(例: 話者A)を選びます

元に戻すときは「統合しない」を選びます[^merge]。

### 話者で絞り込む

特定の人の発言だけを遡って読みたいときに使います。

1. 人型のボタンの右の、絞り込みボタンを押します
2. 読みたい話者にチェックを付けます

選んでいない発言は「ほかの発言 N件」の線にまとまり、押すと開きます。
絞り込むのは表示だけで、保存するMarkdownやAIエージェントへの送信は会話の全体のままです。

### 発言の音声を聞く

誰の声か分からない発言は、元の音声のその部分だけを聞いて確かめられます。

1. 発言の行にマウスを乗せ、時刻の右の▶を押します
2. その発言の前後を少し含めて流れ、終わると止まります。途中で止めるときは■を押します

:::note
聞けるのは、元の音声が残っている会議の停止後です[^playback]。

- 録音: 設定で `saveRecording = true` にして録った会議
- 音声ファイルの書き起こし: 「仕上げ中」になってから
:::

## 小さな声を除外する

隣の会議の声のように、離れた場所の小さな声を書き起こしから外せます。

1. 開始シートの「小音量除外」をオンにして、録音を始めます
2. 録音中にウィンドウ上部の人型のボタンを押し、しきい値を調整します。既定は −45 dBFS です

除外した行は半透明で残り、「小音量のため除外」と出ます。
コピー・AIエージェントへの送信・Markdownの本文からは外れます[^exclude]。

:::note
入力の音量で判定するので、マイクや入力の音量を変えたら、しきい値を調整し直してください。
:::

## 手入力と画像

会議中に共有されたURLや補足を、発言と同じ流れへ書き込めます。

1. 本文とフッターの間の入力欄に書きます
2. 画像を添えるときは、入力欄で⌘Vを押します
3. ⌘Enterで投稿します

投稿した行は「手入力」という名前で、発言と時刻順に並びます[^typed]。

## 画面を記録する

会議中に映している資料やアプリの画面を、そのとき話していた発言と一緒に残せます。

1. 開始シートの「画面」で、記録するディスプレイを選んで始めます
2. 画面が変わって落ち着くと、KIKIGAKIが1枚撮ります。誰も話していない間に変わった画面は、話し始めたときに最後の1枚だけを残します
3. 残したい場面があれば、フッターのディスプレイ名を押して「いま撮る」を選びます
4. 撮った画面は、そのとき話していた発言の右に並びます
5. 画面を押すと原寸で開きます。←→で前後の画面へ移れます

「+N枚」を押すと省略された画像が開き、「畳む」で戻せます。

画像が小さくて読みにくいときは、発言と画像の境目を左へドラッグすると、画像が大きくなります。変えた幅は次の録音でも使います。

:::note
動く画像や動画が映り続ける画面は、落ち着くのを待たずに1枚撮ります。その後は動いている所を比べず、ほかの所が変わったときだけ撮ります。全画面の動画は最初の1枚だけです。

少し前に撮った画面へすぐ戻ったときや、2つの画面を行き来しているときは、同じ画面を撮り直しません。残したい場面は「いま撮る」で撮ってください。
:::

### 録音中に記録を切り替える

フッターのピンの左に、いま記録しているディスプレイの名前が出ます。記録していないときは「撮らない」と出ます。

- 別のディスプレイに替える: 名前を押して、メニューからディスプレイを選びます
- 記録を止める: メニューから「撮らない」を選びます
- 途中から記録を始める: 「撮らない」で始めた録音でも、メニューからディスプレイを選べば記録を始めます

記録を止めた所と、また始めた所は、書き起こしとMarkdownに「記録を停止」「記録を再開」の行として残ります。

:::note
一時停止中に選んだディスプレイは、再開してから記録します。録音中に替えたディスプレイは、次の録音の開始シートには引き継ぎません。
:::

画像は保存先の `<会議名>.captures/` に保存し、Markdownに埋め込みます[^screen]。
AIエージェントの参加を使うときは、会話から画像の場所が渡り、AIエージェントが必要なときに読みます。詳細: [データの行き先](../data/)

:::caution
選んだディスプレイに映るものは、通知なども含めてそのまま残ります。KIKIGAKIのウィンドウとマウスカーソルは写りません。
:::

:::note
黙って画面を替えている間は、新しい画面がすぐには並びません。話し始めるか、AIエージェントへ送るか、会話をコピーすると、その時点の画面が並びます。
:::

:::note
初めて画面を記録するときは、macOSの画面収録の許可が要ります。許可するまでの録音では画面を残せません。手順は [困ったとき](#画面が記録されない) を見てください。
:::

## 録音済みの音声ファイルを書き起こす

ボイスメモなどで先に録っておいた音声も、録音と同じように話者付きで書き起こせます。
m4a・mp3・wavなど、Macで再生できる音声を読めます。

1. 録音していないときに、書き起こしウィンドウへ音声ファイルをドロップします[^drop]
2. 開始シートで話者判別などを選び、開始します
3. 書き起こしが終わると保存して、「仕上げ中」になります
4. 話者を直したり、AIエージェントに議事録を頼んだりします
5. ヘッダーの「完了」を押します

書き起こしは、1時間の音声で30秒前後が目安です。
会議の日時は、音声ファイルに記録された日時を使います。

:::caution
- 書き起こし中に「中止」を押すかKIKIGAKIを終了すると、途中の結果は保存しません
- 「完了」を押した後は、AIエージェントへ新しく頼めません
:::

## 保存されるファイル

停止すると、会議ごとにMarkdownを1つ、`~/Documents/KIKIGAKI` に保存します[^output]。

```
~/Documents/KIKIGAKI/
├── 2026-09-05_1240.md              会議のMarkdown
├── 2026-09-05_1240.wav             録音。saveRecording = true のときだけ
├── 2026-09-05_1240.attachments/    手入力に貼った画像
├── 2026-09-05_1240.captures/       画面の記録。画面を記録したときだけ
└── .kikigaki-context/              AIエージェントへ渡した会話の記録
```

Markdownは次の形です。

```markdown
# KIKIGAKI 2026-09-05 12:40

- 開始: 2026-09-05 12:40
- 長さ: 32:15
- 話者: A=田中, B=佐藤

## 書き起こし

- [12:40:05] 田中: では始めます。
- [12:40:12] 佐藤: よろしくお願いします。
```

保存されるものの全体は [データの行き先](../data/) で説明します。

:::caution
会議のMarkdownは、停止後に話者名を変えたときや、AIエージェントの返事が届いたときにKIKIGAKIが書き直します。手で編集した内容は上書きされるので、残したいメモは別のファイルに書いてください。
:::

### 録音中の途中保存

録音中も1分ごとと一時停止したときに、同じMarkdownへ途中の記録を書きます。
KIKIGAKIが途中で落ちても、最後に書けたところまでは残ります。
停止すると、最終結果で書き直します[^interim]。

## そのほかの操作

| 操作 | 方法 |
| --- | --- |
| 一時停止・再開 | ウィンドウ上部のボタンか、メニューバーのメニュー |
| 検索 | ⌘F |
| 文字の大きさ | ⌘+・⌘-・⌘0。発言と議事録の文字が80%〜200%で変わります |
| 最新の発言へ戻る | 「最新の発言」を押す |
| 最前面に固定 | フッターのピンボタン |

マイクだけで録音しているときにマイクをつなぎ替えると、新しい既定のマイクへ自動で乗り換えて録音を続けます。

## 困ったとき

### 画面が記録されない

ヘッダーに「画面を記録できません」と出たら、理由に合わせて直します。録音と書き起こしはそのまま続きます。

- 「画面収録」の許可がありません: システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音 で、KIKIGAKIを許可してください。許可した後に、フッターのメニューでディスプレイを選び直すと記録を始めます
- ディスプレイが見つかりません: 録音の途中で外したディスプレイは、つなぎ直しても自動では追いかけません。つなぎ直した後に、フッターのメニューでディスプレイを選び直してください

記録できなくなっている間は、フッターのディスプレイ名が赤くなります。選び直して記録を始められると、ヘッダーの表示は消えます。

[^sheet]: 設定ファイルは書き換えません。自動送信と手動送信の行は、設定でAIエージェントの参加を有効にしたときだけ出ます。
[^next]: 候補にマウスを乗せて×を押すと、予約を消せます。登録から24時間経った予約も消えます。予約の時刻に録音が自動で始まることはありません。
[^rename]: 1行だけを別の話者へ付け替えることはできません。新しい録音を始めると、名前は既定の「話者A」などに戻ります。
[^participants]: 議事録で `attendees` など別の名前で参加者を書いている場合は、設定の `participantsKey` で指定します。
[^merge]: 統合は話者のすべての発言に効き、発言ごとに分け直すことはできません。
[^playback]: 録音中は聞けません。鳴らした声をマイクが拾ってしまうためです。新しい録音を始めると、前の会議の発言は聞けなくなります。録音のWAVや取り込んだ音声ファイルを消したり移したりした場合も聞けません。
[^exclude]: Markdownの末尾の「小音量で除外した発話」には全文が残ります。
[^typed]: 画像は保存先の `<会議名>.attachments/` に保存し、Markdownに埋め込みます。投稿しても、AIエージェントへの送信は始まりません。書き込めるのは録音中と一時停止中だけです。
[^screen]: 初回は「撮らない」です。次回からは前回の選択を使います。一時停止中は撮らず、録音済みの音声ファイルの書き起こしでは記録しません。
[^drop]: メニューバーのメニューの「音声ファイルから書き起こす…」からも選べます。動画ファイルは扱いません。元の音声のコピーは保存せず、Markdownにファイル名を残します。
[^output]: 保存先は設定の `outputDir` で変えられます。メニューバーのメニューの「保存先を開く」で開けます。
[^interim]: 途中の記録には「状態: 録音中の途中保存」の行が付きます。この行が残っているMarkdownは、録音の途中で終わった記録です。間隔は設定の `autoSaveIntervalSeconds` で変えられます。
