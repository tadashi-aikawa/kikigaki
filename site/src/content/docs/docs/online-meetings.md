イヤホンでオンライン会議をするときに、相手の声も自分の声と一緒に文字起こしできるようにします。

## なぜ設定が要るか

KIKIGAKIはマイクの音を聴いて文字起こしします。

- スピーカーで会議をしているときは、スピーカーから出た相手の声をマイクが拾うので、そのまま文字になります
- イヤホンでは相手の声がマイクに届かないので、マイクだけでは自分の声しか文字になりません

そこで、Macで再生中の音(システム音声)を取り込み、マイクの音と混ぜてから文字起こしします。

## 開始シートで選ぶ

録音開始シートの「システム音声」で、3つから選びます。

| 選択 | 取り込み |
| --- | --- |
| 自動 | 既定の出力がイヤホン・ヘッドホンと判定できたときだけ取り込む |
| 取り込む | 出力の種類によらず取り込む |
| 取り込まない | 取り込まない。マイクだけを聴く |

- 既定は前回の選択で、初回は「自動」です
- 「自動」には、いまの判定が `自動(いまは取り込む)` のように出ます。シートを開いている間に出力を切り替えると、表示も変わります
- 取り込むかどうかは録音を始めた時点で決まり、その会議の間は変わりません。録音中にイヤホンを抜き差ししても追従しません

### 「自動」の判定

| 既定の出力 | 「自動」での扱い |
| --- | --- |
| イヤホン・ヘッドホン | 取り込む |
| 内蔵スピーカー | 取り込まない |
| 判定できない出力 | 取り込まない |

- 内蔵スピーカーで取り込まないのは、マイクが拾った相手の声と取り込んだ相手の声が、二重に入るためです
- 判定できない出力には、USBのオーディオ機器や外部モニターがあります。その先がイヤホンかスピーカーか分からないので、取り込みません。取り込みたいときは「取り込む」を選んでください
- 会議アプリがMacの既定とは別の出力を使っていると、判定が外れます。そのときも「取り込む」「取り込まない」を明示してください

## イヤホンで使う手順

1. イヤホンを接続し、Macの既定の出力にします
2. KIKIGAKIで「録音を開始」を押し、システム音声の行が `自動(いまは取り込む)` になっていることを確かめます。判定できない出力なら「取り込む」を選びます
3. 開始します
4. 初回は、macOSが「システムオーディオ録音」の許可を求めます。許可してください

## 取り込まれる音

- Macで鳴っているすべての音を取り込みます。会議アプリの音だけには絞れません
    - 例: 通知音や、会議と別に流している動画の音も入ります
    - 会議中はほかの音を止めておくと、余計な文字が入りません
- 自分の声と相手の声は1本に混ぜて文字起こしします。声が重なった部分は崩れます。交互に話す会議を前提にしています
- 自分の声は、相手の声より小さく入ることが多いです。声が重なると、自分の声や相づちが文字にならないことがあります
- 混ぜた後の音に対して、話者判別・小音量除外・録音WAVの保存が働きます。相手も自分も、最大8人の話者の中で判別します

## 許可

- 取り込む会議の初回に、macOSが「システムオーディオ録音」の許可を求めます
- 画面収録の許可は要りません
- 許可しなかった場合は、システム音声の側が無音になるだけで、マイクの声は文字になります。後から許可するときは、システム設定の「プライバシーとセキュリティ」から変えてください

## うまく取り込めないとき

取り込みの準備や録音中の取り込みに失敗しても、会議は止めません。

- マイクだけに切り替えて録音を続け、理由をウィンドウのヘッダーに1行で出します
- Bluetoothイヤホンが切れたときも同じです
- 取り込み中であることを常に示す表示はありません。表示が出るのは失敗したときだけです
