title: オンライン会議で使う

イヤホンでのオンライン会議でも、相手の声と自分の声を一緒に書き起こせます。

## なぜ設定が要るか

KIKIGAKIはマイクの音を聴いて文字起こしします。
イヤホンで会議をすると、相手の声はマイクに届きません。
そこで、Macで鳴っている音(システム音声)も取り込み、マイクの音と混ぜてから文字起こしします。

![イヤホンでマイクだけのときは自分の声だけが文字になり、システム音声も取り込むと相手の声と混ぜて両方が文字になる図](/kikigaki/diagrams/system-audio.svg)

## イヤホンで使う手順

1. イヤホンを接続し、Macの既定の出力にします
2. 「録音を開始」を押し、開始シートの「システム音声」が `自動(いまは取り込む)` になっていることを確かめます
3. 開始します
4. 初回だけ、macOSが「システムオーディオ録音」の許可を求めるので、許可します

![録音開始シートのシステム音声の行で「取り込む」を選んだところ](/kikigaki/captures/earphones.webp)

取り込むかどうかは、録音を始めた時点で決まります[^start]。

## 「システム音声」の選び方

| 選択 | 取り込み |
| --- | --- |
| 自動 | 既定の出力がイヤホン・ヘッドホンのときだけ取り込む |
| 取り込む | 出力によらず取り込む |
| 取り込まない | マイクだけを聴く |

ふだんは「自動」のままでかまいません[^auto]。
USBのオーディオ機器や外部モニターから音を出していると、イヤホンかどうかを判定できないことがあります。
そのときは「取り込む」を選びます。

## 知っておくこと

:::note
- Macで鳴っているすべての音を取り込みます。通知音や、会議と別に流している動画の音も入るので、会議中はほかの音を止めておいてください
- 会議アプリの中でミュートした音は取り込めません。会議アプリでスピーカーの音量を0にすると、相手の声は文字になりません
- 自分の声と相手の声が重なると、文字が崩れます。交互に話す会議に向いています
:::

## うまく取り込めないとき

### 「取り込む」が選べない

マイクモードが「声を分離」になっています。
録音を始めてから、コントロールセンターの「マイクモード」でKIKIGAKIを「標準」に戻すと、次の録音から取り込めます。

### 相手の声が文字にならない

システム設定の「プライバシーとセキュリティ」で、KIKIGAKIのシステムオーディオ録音を許可しているか確かめてください。

### 録音中に取り込めなくなった

会議は止めずに、マイクだけに切り替えて録音を続けます。
理由はウィンドウ上部に出ます。
Bluetoothイヤホンが切れたときも同じです。

[^start]: 録音中にイヤホンを抜き差ししても、取り込み方は変わりません。画面収録の許可は要りません。
[^auto]: 内蔵スピーカーでは、「自動」は取り込みません。マイクが拾う相手の声と二重に入るためです。
