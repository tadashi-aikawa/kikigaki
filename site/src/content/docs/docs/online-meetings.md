---
title: オンライン会議で使う
description: イヤホンで相手の声も録る手順と、取り込めないときの対処
---

イヤホンでのオンライン会議でも、相手の声と自分の声を一緒に書き起こせます。

## なぜ設定が要るか

KIKIGAKIはマイクの音を聴いて文字起こしします。

- スピーカーで会議をしているときは、マイクが相手の声も拾います
- イヤホンでは相手の声がマイクに届きません
    - 結果: マイクだけでは、自分の声しか文字になりません

そこで、Macで再生中の音(システム音声)を取り込み、マイクの音と混ぜてから文字起こしします。

## 開始シートで選ぶ

録音開始シートの「システム音声」で、3つから選びます。

| 選択 | 取り込み |
| --- | --- |
| 自動 | 既定の出力がイヤホン・ヘッドホンと判定できたときだけ取り込む |
| 取り込む | 出力の種類によらず取り込む |
| 取り込まない | 取り込まない。マイクだけを聴く |

- 既定は前回の選択で、初回は「自動」です
- 「自動」には、`自動(いまは取り込む)` のように判定が出ます
    - 動き: シートを開いている間に出力を切り替えると、表示も変わります
- 取り込むかどうかは、録音を始めた時点で決まります
    - 制約: 録音中にイヤホンを抜き差ししても、取り込み方は変わりません

### 「自動」の判定

| 既定の出力 | 「自動」での扱い |
| --- | --- |
| イヤホン・ヘッドホン | 取り込む |
| 内蔵スピーカー | 取り込まない |
| 判定できない出力 | 取り込まない |

- 内蔵スピーカーでは取り込みません
    - 理由: マイクが拾う相手の声と二重に入るためです
- USBのオーディオ機器や外部モニターは、出力を判定できないことがあります
    - 理由: その先がイヤホンかスピーカーか分からないためです
    - 操作: 相手の声を取り込みたいときは「取り込む」を選んでください
- 会議アプリがMacの既定とは別の出力を使うと、判定が外れます
    - 操作: 「取り込む」「取り込まない」を自分で選んでください

## イヤホンで使う手順

1. イヤホンを接続し、Macの既定の出力にします
2. KIKIGAKIで「録音を開始」を押し、システム音声が `自動(いまは取り込む)` になっていることを確かめます
    - 例外: 出力を判定できないときは「取り込む」を選びます
3. 開始します
4. 初回に出る、macOSの「システムオーディオ録音」を許可します

## 取り込まれる音

- Macで鳴っているすべての音を取り込みます
    - 制約: 会議アプリの音だけには絞れません
    - 例: 通知音や、会議と別に流している動画の音も入ります
    - 操作: 会議中はほかの音を止めておくと、余計な文字が入りません
- 自分の声と相手の声を混ぜて書き起こします
    - 制約: 声が重なると文字が崩れます。交互に話す会議を前提にしています
- 自分の声は、相手の声より小さく入ることが多いです
    - 結果: 声が重なると、自分の声や相づちが文字にならないことがあります
- 話者判別・小音量除外・WAVの保存は、混ぜた後の音に対して行います
- 話者は相手も自分も合わせて、最大8人まで分けます

## 許可

- 取り込む会議の初回に、macOSが「システムオーディオ録音」の許可を求めます
- 画面収録の許可は要りません
- 許可しなくても、マイクの声は文字になります
    - 制約: システム音声は無音になります
    - 操作: 後から許可するときは、システム設定の「プライバシーとセキュリティ」から変えてください

## うまく取り込めないとき

取り込みの準備や録音中の取り込みに失敗しても、会議は止めません。

- マイクだけに切り替えて録音を続けます
    - 表示: 理由はウィンドウ上部に出ます
- Bluetoothイヤホンが切れたときも同じです
- 取り込み中であることを常に示す表示はありません
    - 表示: 失敗したときだけ理由が出ます
