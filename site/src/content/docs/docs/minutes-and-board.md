---
title: 議事録とボード
description: 議事録を横に開く、AIエージェントに更新を頼む、ボードで論点を見る
---

AIエージェント(Claude Code か Codex のCLI)や自分が書いた議事録を、書き起こしの横で読めます。
いまの論点を図で見るボードと、議事録を指定して会議を始めるリンクも紹介します。

## 議事録ペインを開く

議事録は、ウィンドウの右に開きます。
次のどれでも開く・隠す操作ができます。

- ウィンドウの右上の「議事録」ボタン
- メニューバーのメニューの「議事録を表示」
- 「表示」メニューの「議事録を表示」

開くとウィンドウが右へ広がり、閉じると元の幅に戻ります。
開いているかどうかと幅は、アプリを再起動しても引き継ぎます。

## 表示する議事録を決める

ペインは何も表示しない状態で始まります。
会議を始めただけでは、議事録のファイルは作りません。

表示する議事録は、次の3つの方法で選べます。

| 方法 | 操作 |
| --- | --- |
| 録音開始シート | 「議事録」の欄に絶対パスを入れる。履歴・「ファイルを選ぶ…」・`.md` のドロップからも入れられる |
| ペインのパス欄 | パスを入れてReturnで確定する。Escで編集を取り消す。右端の×で表示をやめる |
| AIエージェントからの通知 | AIエージェントが議事録を作成・更新して場所を知らせると、そのファイルに切り替わる |

- 指定できるのは `.md` のファイルです
- まだ無いファイルも指定できます
    - 動き: ファイルが作られると、自動で表示します
- パス欄にカーソルを置くと、最近表示した10件が出ます
    - 操作: Returnで先頭を開けます
- 開始シートの議事録欄には、前回のパスを入れません
    - 理由: 前の会議の議事録を上書きしないためです
- AIエージェントの参加を設定していなくても、自分で書く議事録の表示に使えます

## 議事録を読む

文字の倍率を変えると、Mermaidの図も同じ倍率で大きくなります。
広い図は縮めずに表示し、その図の枠で横スクロールして見られます。

枠の外に続きがある辺には、薄いぼかしと小さな矢印が出ます。

Mermaidの図をクリックすると、紫の枠と手のひらカーソルが出ます。

- 選んだ図は、ピンチで25%〜400%に拡大縮小できます
    - 中心: カーソルの位置です
- ドラッグと2本指スクロールで、図の中を動かせます
- 枠の右上の「− 倍率 +」でも拡大縮小できます
    - 配置: 目次に重なるときは左側へ寄せます。幅が足りないときは目次の下に表示します
- 「全体」で、図の全体が枠に収まる倍率へ変えます
    - 下限: 25%でも収まらない図は、25%で中央に置きます
- 「戻す」で、図を等倍・初期位置へ戻せます
- Escか図の外のクリックで、選択を解除します
    - 動き: ペインのスクロールへ戻ります
    - 表示: 選択枠と図のフォーカス表示が消えます
- 図の枠は、更新後の図の大きさに追従します
    - 拡大縮小・ドラッグ: 枠の中の見え方だけが変わります
- AIの更新後も、図の倍率と位置は引き継ぎます
    - 例外: 別の議事録へ切り替えると初期に戻ります
- 図の更新中は前の表示を保ち、新しい図ができてから差し替えます
- ⌘+・⌘-・⌘0は、これまでどおり文字の倍率を変えます
    - 関係: 図の倍率と掛け合わせて表示します

ボードタブのキャンバスは、選ばずに操作できます。

120Hzの画面では、図の操作も画面の更新頻度に追従します。
60Hzの画面では、従来どおり約60コマで動きます。

ペインは読むためのもので、ファイルを書き換えません。
ファイルが更新されると、表示も追いつきます。

- 追加・書き換えされた箇所は、淡い紫で4秒強調します
    - 表示: 目次の見出しにも紫の丸が付きます
- AIエージェントへ依頼を送ってから次の依頼までは、その依頼で変わった箇所の強調を残します
- 下端に最終更新の時刻を表示します
- 右上の「目次」で見出しの一覧が出ます
- 見出しの左の三角で、その下の内容を畳めます
- ⌘Fで、カーソルのあるペインを検索します
- 画像はクリックで拡大します
- コードブロックは、右上のコピーアイコンで中身をコピーできます
- パス欄の右のボタンから、NeovimかObsidianでファイルを開けます
    - 条件: Obsidianは、ファイルがVaultの中にあるときに使えます
- 4 MiBを超えるファイルは表示しません

ペインを隠している間にAIエージェントが議事録を知らせてきたら、フッターに「議事録」の印が出ます。
押すとペインが開きます。

### 対応する記法

見出し・リスト・表・リンク・強調のほか、次の記法を表示します。

- タスク `[ ]` `[x]`
    - 制約: 表示だけで、チェックはできません
- 脚注 `[^1]`
- callout `> [!NOTE]`、MySTやMkDocs形式のadmonition
- Mermaidの図
- 数式 `$...$` `$$...$$`
- `[[ノート]]` 形式のWikiリンク
    - 動き: 議事録がObsidianのVaultの中なら、クリックで同名ノートを開きます
- `[[#見出し]]` で議事録の中の見出しへ移動します
- ローカルとHTTP・HTTPSの画像
    - 通信: 外部の画像URLは、その配信元へ取りに行きます

## AIエージェントに議事録を書かせる

[AIエージェントを会議に参加させる](../ai-participant/) の設定を済ませ、議事録の更新を頼みます。

```toml
[[ai]]
cli = "codex"
address = "迅雷へ"
initialPrompt = "会議の決定事項と担当・期限をMarkdown議事録へ更新してください"
```

- 議事録のパスを指定していれば、AIエージェントはそのファイルへ書きます
- 指定していなければ、AIエージェントが依頼文に従って書き先を決めます
    - 動き: 保存した場所を知らせると、KIKIGAKIがそのファイルを表示します
- 自動送信を使うと、会議が進むたびに議事録を書き進めてもらえます

AIエージェントが書ける場所はCLIの権限で決まります。

- Codexには、KIKIGAKIの保存先 `outputDir` への書き込みを許可して起動します
- それ以外の場所へ書くときは、CLIが承認を求めることがあります
    - 操作: [herdr](https://herdr.dev/) のペインで承認すると保存されます

「会話をコピー」で渡すときも、表示中の議事録があればその場所を渡します。

## ボード

ボードは、いま何を話し、何が決まったかをAIエージェントが図にまとめたものです。
議事録の1つの見出しの下に、自動送信のたびに書き直します。
手動の依頼は議事録の本文を、自動送信はボードを担当します。

### 設定する

```toml
[[ai]]
name = "議事録とボード"
cli = "codex"
address = "迅雷へ"
board = "## ボード"
boardLocation = "~/Documents/minutes/${yyyyMMdd_HHmmss}.md として作成し、変数は現在日時"
initialPrompt = "議事録を更新してください"
autoStart = true
autoIntervalMinutes = 1
```

- `board` は、ボードにする見出しを1行で書きます
- 自動送信には、内蔵のプロンプトを使います
- `initialPrompt` は、手動の依頼の初期値に使います
- `boardLocation` は、議事録のパスが無いときの書き先をAIエージェントに伝えます
    - しくみ: `${...}` や `~` はAIエージェントが解釈します
- 自動送信を始めるには、議事録のパスか `boardLocation` が要ります
    - 例外: どちらも無いと「ボードの自動送信には議事録のパスか boardLocation が必要です」と出て始まりません
- プロンプトを全部差し替えたいときは `boardPrompt` を使います

### 読む

議事録ペインに「議事録」と「ボード」のタブが出ます。
ボードのタブには、最後に更新した時刻が `ボード 17:48` のように付きます。

ボードは、Mermaid図1枚をペインいっぱいに表示します。

- 最初は図全体が見える倍率で表示します。「全体」で同じ見え方へ戻せます
    - 倍率: 小さい図は200%まで、大きい図は25%まで調整します
- 選ばずにピンチ・ドラッグ・2本指スクロールで操作できます
- 「− 倍率 + 全体 戻す」は常に表示します
- 図が枠に収まらない間は、右下のミニマップで全体と表示範囲を示します
    - 配置: フォーカス中の論点に重なるときは、他の隅へ移します
    - 表示: 文字を省き、カードの色と点線を写した箱と線で示します。操作中は少し遅れて追いつきます
    - 大きさ: 縦横比を保ち、ペインの幅の50%・高さの40%以内に収めます。広いペインでは大きく表示します
    - 操作: クリックやドラッグした場所へ移動します
- 旧ボードの複数図や文章は、左下の「以前の本文」を開いて読めます

| 図の印 | 意味 |
| --- | --- |
| 印なし | これから決めること |
| ✅ | 決まった |
| 🟠 | 保留 |
| ❌ | 却下 |
| 💬 | 決める対象ではない前提や所感 |

- 紫の太い枠が、いま話している論点です
- 直前の更新で動いた論点は紫の枠、しばらく動いていない論点は灰色になります
- 論点には T1、T2 の番号が付きます
    - 表示: 図の配置が変わっても、番号は変わりません
- 論点をクリックすると、その位置のまま墨色の四隅の印で目立たせます
    - 見出しへの移動: フォーカス中の論点をもう一度クリックします
    - 解除: Escか図の余白をクリックします
- 図が更新されても、フォーカスした論点の位置と倍率を保ちます
    - 更新中: 前の図を表示したまま操作できます。新しい図ができてから差し替えます
    - フォーカスがない場合: ズームや移動で見ていた中央に近い論点の位置を保ちます
    - 全体を見ていた場合: 新しい図全体が見えるように調整します

ボードタブで⌘Fを押すと、「ボードを検索」が開きます。

- 図の論点の文字を検索します
    - 対象外: 辺のラベルと「以前の本文」です
- 次・前へ移動すると、一致した論点を中央へ寄せてフォーカスします
    - 倍率: 図が100%未満なら100%へ上げます。100%以上なら今の倍率を保ちます
- 件数は、文字列が一致した回数を表示します
- タブを切り替えても検索語は残ります
    - 動き: 開いたタブの内容を検索し直します
- 検索を閉じると、一致の強調だけが消えます
    - 表示: 論点のフォーカスは残ります

### 限界

- ボードは、送信から1〜2分遅れて会議を映します
    - 理由: 返事を待つ間は次の送信を飛ばします。更新の間隔はAIエージェントの返事にかかる時間で決まります
- 話者判別の誤りや音声認識の誤字は、そのまま論点名に入ります
- ボードは会議の要約で、議事録の代わりにはなりません
- 図の配置は、論点が1つ増えるだけで大きく変わることがあります
