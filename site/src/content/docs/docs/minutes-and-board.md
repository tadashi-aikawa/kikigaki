title: 議事録とボード

AIや自分が書いた議事録を、書き起こしの右に並べて読みながら会議を進められるようにします。
議論の現在地をAIに図にさせるボードと、議事録を指定して録音を始めるリンクも説明します。

## 議事録ペインを開く

議事録はウィンドウの右のペインに表示します。
ペインを開く・隠す操作は次のどれでもできます。

- ウィンドウの右上の「議事録」ボタン
- メニューバーのメニューの「議事録を表示」
- 「表示」メニューの「議事録を表示」

開くとウィンドウが右へ広がり、閉じると元の幅に戻ります。
開いているかどうかと幅は、アプリを再起動しても引き継ぎます。

## 表示する議事録を決める

ペインは何も表示しない状態で始まります。
会議を始めただけでは、議事録のファイルは作りません。

表示する議事録は次の3つの方法で決まります。

| 方法 | 操作 |
| --- | --- |
| 録音開始シート | 「議事録」の欄に絶対パスを入れる。履歴・「ファイルを選ぶ…」・`.md` のドロップからも入れられる |
| ペインのパス欄 | パスを入れてReturnで確定する。Escで編集を取り消す。右端の×で表示をやめる |
| AIからの通知 | AIが議事録を作成・更新して場所を知らせると、そのファイルに切り替わる |

- 指定できるのは `.md` のファイルです
- まだ無いファイルも指定できます。作成されると自動で表示します
- パス欄にカーソルを置くと、最近表示した10件が出ます。Returnで先頭を開けます
- 開始シートの議事録欄には、前回のパスを入れません。前の会議の議事録を上書きしないためです
- AI参加を設定していなくても、自分で書く議事録の表示に使えます

## 議事録を読む

ペインは読むためのもので、ファイルを書き換えません。
ファイルの変更を見張っていて、保存されるたびに描き直します。

- 更新で追加・書き換えされた箇所を、淡い紫で4秒強調します。目次の見出しにも紫の丸が付きます
- AIへ依頼を送ってから次の依頼までは、その依頼で変わった箇所の強調を残します
- 下端に最終更新の時刻を表示します
- 右上の「目次」で見出しの一覧を開けます。見出しの左の三角で配下を畳めます
- ⌘Fで、カーソルのあるペインを検索します
- 画像はクリックで拡大します
- パス欄の右のボタンで、NeovimかObsidianでファイルを開けます。ObsidianはファイルがVaultの中にあるときに使えます
- 4 MiBを超えるファイルは表示しません

ペインを隠している間にAIが議事録を知らせてきたら、フッターに「議事録」の印が出ます。
押すとペインが開きます。

### 対応する記法

見出し・リスト・表・リンク・強調のほか、次の記法を描画します。

- タスク `[ ]` `[x]`。表示だけで、チェックはできません
- 脚注 `[^1]`
- callout `> [!NOTE]`、MySTやMkDocs形式のadmonition
- Mermaidの図
- 数式 `$...$` `$$...$$`
- `[[ノート]]` 形式のWikiリンク。議事録がObsidianのVaultの中にあるときは、クリックでObsidianの同名ノートを開きます
- `[[#見出し]]` で議事録の中の見出しへ移動します
- ローカルとHTTP・HTTPSの画像。外部の画像URLは、その配信元へ取りに行きます

## AIに議事録を書かせる

[AIを会議に参加させる](../ai-participant/) の設定をしたうえで、議事録の更新を依頼します。

```toml
[[ai]]
cli = "codex"
address = "迅雷へ"
autoPrompt = "会議の決定事項と担当・期限をMarkdown議事録へ更新してください"
```

- 議事録のパスを指定していれば、AIはそのファイルへ書きます
- 指定していなければ、AIは依頼文に従って書き先を決め、保存した場所を知らせます。KIKIGAKIはそのファイルを表示します
- 自動送信と組み合わせると、会議の進行に合わせて議事録が育ちます

AIが書ける場所はCLIの権限で決まります。

- Codexには、KIKIGAKIの保存先 `outputDir` への書き込みを許可して起動します
- それ以外の場所へ書くときは、CLIが承認を求めることがあります。herdrのペインで承認すると保存されます

「会話をコピー」で渡すときも、表示中の議事録があればその場所を渡します。

## ボード

ボードは、議事録のファイルの中の1つの見出しを、自動送信のたびにAIが更新する「議論の現在地」です。
手動の依頼は議事録の本文を、自動送信はボードを担当します。

### 設定する

```toml
[[ai]]
name = "議事録とボード"
cli = "codex"
address = "迅雷へ"
board = "## ボード"
boardLocation = "~/Documents/minutes/${yyyyMMdd_HHmmss}.md として作成し、変数は現在日時"
autoPrompt = "議事録を更新してください"
autoStart = true
autoIntervalMinutes = 1
```

- `board` は、ボードにする見出しを1行で書きます
- 自動送信で使うプロンプトは内蔵のものです。`autoPrompt` は手動の依頼の初期値に使います
- `boardLocation` は、議事録のパスが無いときにAIへ伝える書き先の作り方です。`${...}` や `~` はAIが解釈します
- ボードの自動送信を始めるには、議事録のパスか `boardLocation` のどちらかが要ります。どちらも無いと「ボードの自動送信には議事録のパスか boardLocation が必要です」と出て始まりません
- プロンプトを全部差し替えたいときは `boardPrompt` を使います

### 読む

議事録ペインに「議事録」と「ボード」のタブが出ます。
ボードのタブには、最後に更新した時刻が `ボード 17:48` のように付きます。

ボードは、Mermaidの図・立場・直近の動きの順に並びます。

| 図の印 | 意味 |
| --- | --- |
| 印なし | これから決めること |
| ✅ | 決まった |
| 🟠 | 保留 |
| ❌ | 却下 |
| 💬 | 決める対象ではない前提や所感 |

- 紫の太い枠が、いま話している論点です
- 直前の更新で動いた論点は紫の枠、しばらく動いていない論点は灰色になります
- 論点には T1、T2 の番号が付き、図の配置が変わっても番号は変わりません
- 「立場」の表は、意見が割れている論点だけを話者ごとに並べます
- 議事録に対応する見出しがある論点は、押すとその見出しへ移動します

### 限界

- ボードは送信から1〜2分遅れて会議を映します。返事を待つ間は次の送信を飛ばすので、更新の間隔はAIの応答時間で決まります
- 話者判別の誤りや音声認識の誤字は、そのまま論点名や立場に入ります
- ボードは会議の要約で、議事録の代わりにはなりません
- 図の配置は、論点が1つ増えるだけで大きく変わることがあります

## kikigaki:// のリンク

`kikigaki://start` のリンクを開くと、議事録を入れた状態の録音開始シートが出ます。

```text
kikigaki://start?minutes=%2FUsers%2Fyou%2FDocuments%2Fminutes%2Fweekly.md
```

- `minutes` には、議事録の絶対パスをパーセントエンコードして渡します。`~/` から始まるパスも使えます
- リンクから録音は始まりません。開始は自分で押します
- 録音中・準備中・保存中に開いたときは、シートを出さず、ヘッダーに理由を出します
- 読めないパスだったときは、議事録欄の下に理由を出します

会議の前に議事録のファイルを用意し、予定やノートにこのリンクを貼っておくと、会議の開始時にクリックだけで議事録を指定できます。
