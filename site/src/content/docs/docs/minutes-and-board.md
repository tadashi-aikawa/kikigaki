AIエージェント(Claude Code か Codex のCLI)や自分が書いた議事録を、書き起こしの横で読めます。
いまの論点を図で見るボードも紹介します。

![議事録ペインに、決まったことと担当と期限の見出しが並ぶ議事録](/kikigaki/captures/minutes.webp)

## 議事録ペインを開く

1. 録音開始シートの「議事録」の欄に、議事録の `.md` のパスを入れます[^path]
2. 録音を始めると、ウィンドウの右に議事録ペインが開きます

ウィンドウの右上の「議事録」ボタンで、ペインを開いたり隠したりできます。
録音の途中で別の議事録に替えるときは、ペインのパス欄にパスを入れてReturnを押します。

まだ無いファイルも指定でき、作られると表示します。
AIエージェントの参加を設定していなくても、自分で書く議事録の表示に使えます。

## 議事録を読む

ペインは読むためのもので、ファイルを書き換えません。
ファイルが更新されると表示も追いつき、追加・書き換えされた箇所を淡い紫で強調します。

- 目次: 右上の「目次」で見出しの一覧が出ます
- 検索: ⌘F
- 編集: パス欄の右のボタンから、NeovimかObsidianでファイルを開けます
- 図: Mermaidの図は、クリックして選ぶとピンチやドラッグで拡大・移動できます

見出し・リスト・表・リンクのほか、タスク・脚注・callout・Mermaid・数式・`[[ノート]]` 形式のWikiリンク・画像を表示します[^render]。

## AIエージェントに議事録を書かせる

会議の会話をAIエージェントへ送り、議事録を書いてもらいます。
書かれた議事録は、そのままペインに出ます。

![会議の会話がAIエージェントへ送られ、AIエージェントが議事録ファイルを書き、議事録ペインに表示される流れの図](/kikigaki/diagrams/minutes-flow.svg)

1. [AIエージェントを会議に参加させる](../ai-participant/) の準備を済ませます
2. 宛先の `initialPrompt` に、議事録の更新を頼む文を書いておきます

    ```toml
    [[ai]]
    cli = "codex"
    address = "迅雷へ"
    initialPrompt = "会議の決定事項と担当・期限をMarkdown議事録へ更新してください"
    ```

3. 開始シートで議事録のパスを指定して、録音を始めます
4. 手動か自動で送ります。自動送信にすると、会議が進むたびに議事録を書き進めてもらえます

:::note
- 議事録のパスを指定しなければ、AIエージェントが依頼文に従って書き先を決め、書いた場所をKIKIGAKIへ知らせます
- Codexには、KIKIGAKIの保存先 `outputDir` への書き込みを許可して起動します。それ以外の場所へ書くときは、CLIが承認を求めることがあるので、herdrのペインで承認してください
:::

## ボード

ボードは、いま何を話し、何が決まったかをAIエージェントが図にまとめたものです。
自動送信のたびに書き直します。

![ボードのタブ。論点と決まったことがカードの木で並び、現在地のカードが紫で強調されている](/kikigaki/captures/board.webp)

### 設定する

宛先の `[[ai]]` に、ボードにする議事録の見出しを `board` で書きます。
自動送信でボードを、手動の依頼で議事録の本文を書いてもらいます。

```toml
[[ai]]
name = "議事録とボード"
cli = "codex"
address = "迅雷へ"
board = "## ボード"
boardLocation = "~/Documents/minutes/${yyyyMMdd_HHmmss}.md として作成し、変数は現在日時"
initialPrompt = "議事録を更新してください"
autoStart = true
autoIntervalMinutes = 1
```

議事録のパスを指定しない会議では、`boardLocation` で書き先をAIエージェントに伝えます[^board]。

### 読む

議事録ペインの「ボード」タブを開きます。
紫の太い枠が、いま話している論点です。

| 図の印 | 意味 |
| --- | --- |
| 印なし | これから決めること |
| ✅ | 決まった |
| 🟠 | 保留 |
| ❌ | 却下 |
| 💬 | 決める対象ではない前提や所感 |

- 移動・拡大: ピンチ・ドラッグ・2本指スクロール。「全体」で図全体が見える倍率に戻ります
- 論点を見る: 論点をクリックすると目立ち、もう一度クリックすると議事録のその見出しへ移ります
- 検索: ⌘F

:::note
- ボードは、送信から1〜2分遅れて会議を映します
- 話者判別の誤りや音声認識の誤字は、そのまま論点名に入ります
- ボードは会議の要約で、議事録の代わりにはなりません
:::

[^path]: 「ファイルを選ぶ…」や `.md` のドロップでも入れられます。前の会議の議事録を上書きしないよう、前の会議のパスは引き継ぎません。
[^render]: 外部の画像URLは、表示するときにその配信元へ取りに行きます。4 MiBを超えるファイルは表示しません。
[^board]: 議事録のパスも `boardLocation` も無いと、自動送信が始まりません。
