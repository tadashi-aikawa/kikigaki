AIエージェント(Claude Code か Codex のCLI)に、会議中の議事録や、ひとりで話したアイデアの整理を頼めます。
AIエージェントの参加を設定せずに、会話をコピーしてほかのAIエージェントへ渡す方法もあります。

## しくみ

KIKIGAKIは、[herdr](https://herdr.dev/) の専用ペインでAIエージェントを起動します。
送信すると会話と問いが渡り、返事が書き起こしウィンドウに発言と並びます。

![KIKIGAKIが会話と問いをherdrのペインのAIエージェントへ送り、返事が書き起こしに発言と並んで出る図](/kikigaki/diagrams/ai-flow.svg)

AIエージェントへ会話が渡るのは、送信したときだけです。
手入力に貼った画像と [画面の記録](../recording/#画面を記録する) の画像は、会話に場所だけが入り、AIエージェントが必要なときに開きます。
詳細: [データの行き先](../data/)

## 準備する

### 用意するもの

- [herdr](https://herdr.dev/) と、使うCLIの [herdr連携](https://herdr.dev/docs/integrations/)
- Claude Code か Codex
- `kikigaki-cli`: Homebrewで入れたKIKIGAKIに付属します

:::caution
Claude Codeでは、herdr連携が無いと送信が止まります。
:::

### Skillを導入する

AIエージェントが会話を読むためのSkillを、端末で入れます。

```bash
kikigaki-cli skill install
```

一度入れれば、KIKIGAKIを更新しても入れ直さなくてかまいません[^skill]。

### 設定へ宛先を書く

`~/.config/kikigaki/config.toml` に `[[ai]]` を書き、メニューバーのメニューの「設定を再読込」で読み直します。
次の会議から使えます。

```toml
[[ai]]
cli = "codex" # Claude Codeなら "claude"
address = "迅雷へ"
initialPrompt = "会議の決定事項と担当・期限をMarkdown議事録へ更新してください"
```

- `address`: 宛名です。末尾の「へ」を除いた部分が、会議でのAIエージェントの名前になります
- `initialPrompt`: 送るときの依頼文の初期値です

複数の宛先を書くと、送るときに選べます。1つ目が既定です。

```toml
[[ai]]
name = "議事録"
cli = "codex"
effort = "high"
address = "迅雷へ"
initialPrompt = "会議の決定事項と担当・期限をMarkdown議事録へ更新してください"

[[ai]]
name = "相談"
cli = "claude"
address = "ネオへ"
```

全キーは [設定リファレンス](../configuration/) を参照してください。

### 初回の信頼確認

1. 録音中に初めて送信すると、herdrに「KIKIGAKI 迅雷 14:00」のような専用ワークスペースができ、AIエージェントが起動します
2. KIKIGAKIに「初回設定をherdrで確認してください」と出たら、herdrのペインで内容を確かめて承認します
3. 承認すると、そのまま送信が進みます

確認が出るのは最初の一度だけで、会議ごとには出ません[^trust]。

## 頼む

頼み方は3つあります。

| 頼み方 | 使う場面 |
| --- | --- |
| [手動で頼む](#手動で頼む) | 問いを書いて、そのときだけ頼む |
| [声の合図で送る](#声の合図で送る) | 話しながら、手を止めずに頼む |
| [自動で送る](#自動で送る) | 数分おきに議事録を書き進めてもらう |

### 手動で頼む

1. フッター左端の下段「手動」を押します
2. 開いたシートに問いを書きます
3. ⌘Enterで送ります

![フッターの2段の送信ボタン。上段が自動、下段が手動で、手動は依頼の実行中](/kikigaki/captures/footer.webp)

送るのは、送信を押した時点までの会話です。
2回目からは、前回から変わった部分だけを送ります。

:::tip
- 問い欄を空のまま送ると、会話の末尾でAIエージェントへ向けて話した問いを使います。例: 「迅雷、さっきの案を直して」と話してから送る
- 「手動」の右の ▶ を押すと、シートを開かずに下書きのまま送れます
- 返事を待っている間も、「追記して送る」で追加の指示を送れます
:::

### グローバルキーで送る

`config.toml` に `manualSendHotkey` を書くと、ほかのアプリを使っている間も、そのキーで ▶ と同じ送信ができます[^hotkey]。
送れたかどうかは、音と通知で知らせます。

```toml
manualSendHotkey = "cmd+shift+space"
```

### 声の合図で送る

録音中に「アバンティ」と話すと、手動の宛先へ会話を送れます。
受け付けると短い高い音が鳴り、macOSの通知が出ます。
文面は、その宛先の送信シートの下書きを使います。

:::note
- 合図は10秒以上あけてください。10秒未満の合図は無視します
- 合図の発話も書き起こしに残り、AIエージェントへ送られます
- システム音声を取り込んでいるときは、相手側の声でも合図になります
:::

合図の言葉は変えられます。
共通の合図は `[[speakers]]` や `[[ai]]` より前に、宛先ごとの合図はその `[[ai]]` に書きます。
`[]` にすると、合図を使わなくなります。

```toml
autoSendPhrases = ["アバンティ", "アヴァンティ"]

[[ai]]
name = "議事録"
autoSendPhrases = ["最新に更新してください"]
```

宛先ごとに書いた合図は、共通の合図を置き換えます。

### 自動で送る

数分おきに会話の変わった部分を送り、AIエージェントに議事録を書き進めてもらえます。

1. 録音中に、フッター左端の上段「自動」を押して「自動実行…」を選びます
2. 宛先・依頼文・間隔を選びます。間隔の既定は3分です
3. ⌘Enterで始めます

録音開始シートの「自動送信」の行で宛先を選ぶと、録音と同時に始まります。
設定で `autoStart = true` を付けた宛先は、この行の既定になります。

会話に変わりがないときと、返事を待っている間は送りません[^auto]。
録音を止めると、変わった部分があれば最後の1回を送ります。

止めるときは、「自動」のメニューの「自動実行解除」を選びます。
宛先や間隔を変えるときは、止めてから「自動実行…」で入れ直します。

### 作業の許可

手動と自動の送信シートの「作業を許可する(ファイル編集・コマンド実行)」で、AIエージェントに作業まで任せるかを決めます。

| 状態 | AIエージェントがすること |
| --- | --- |
| オン | ファイル編集やコマンド実行などの作業に入ってよい |
| オフ | 回答と提案まで。作業には入らない |

初期値は設定の `allowWork` で、既定はオンです。

:::note
このスイッチでCLIの権限は変わりません。実際の操作は、CLIの権限設定とherdrのペインでの承認に従います。
:::

## 返事を受け取る

### 返事を読む

AIエージェントの返事は、発言と同じ形の行で並びます。

![発話の行の間に並ぶAIエージェントの返事。見出しと箇条書きの下にモデルと作業ディレクトリが出ている](/kikigaki/captures/ai-reply.webp)

返事を待つ間は、進み具合が出ます。
「取消」を押すと待つのをやめます。AIエージェントの処理は止まりません。

![返事を作成中の進行表示。送信・読込・編集・返答の4分割のバーと取消ボタンが出ている](/kikigaki/captures/ai-progress.webp)

### 返事が届いたら音と通知で知らせる

人が待っている返事が届くと、音とOS通知で知らせます。
通知を押すと、書き起こしウィンドウが前に出ます。

既定では、手動で頼んだ返事と確認質問を知らせ、自動送信の返事は知らせません。
宛先ごとに `notifySound`(音)と `notifyBanner`(通知)で変えられます[^notify]。

```toml
[[ai]]
name = "議事録"
notifySound = false # 音だけ止める
```

### 確認質問に返答する

AIエージェントが確認を返してきた行には、朱の「要返答」が付きます。

1. その行の「返答する」を押します
2. 返答を書いて、⌘Enterで送ります

:::tip
- 声で答えてもかまいません。次に送ったときに、AIエージェントが会話から答えを拾います
- AIエージェントへ送らずに片付けるときは「返答済みにする」を押します
:::

### 会議のMarkdownに残るもの

AIエージェントとのやりとりは、会議のMarkdownの `## AIとのやりとり` に、送った文と返事の組で残ります。
録音を止めた後に届いた返事も、同じMarkdownへ残ります[^late]。

## ほかの使い方

### 話者の名前をAIに付けてもらう

宛先の `[[ai]]` に `identifySpeakers = true` を書くと、会話を送るたびに、AIが話者の名前を推定します。
名乗りや、名前で呼ばれたやりとりを手がかりにします。

<video src="/kikigaki/demos/speaker-names.mp4" aria-label="話者Aや話者Bの名前が、AIエージェントの推定で青木や森に変わるところ" autoplay loop muted playsinline controls preload="metadata"></video>

AIが付けた名前には紫の印が付きます。
次の順に確かめます。

1. 「?」付きの名前から見ます。自信の低い推定です
2. 印にマウスを重ねて、推定の根拠を読みます
3. 名前をクリックし、正しければ同じ名前のままReturnを、違っていれば直した名前を入れます

確かめた名前は、以後AIが変えません。

:::note
- 「?」付きの名前は、確かめるまで、後の会話で変わることがあります
- 会話に名前が一度も出てこない人には付きません
:::

会議の間ずっと名前を付けてほしいときは、自動送信と組み合わせます。
録音済みの音声ファイルでは、書き起こしの後にこの宛先へ頼みます。
詳細: [録音済みの音声ファイルを書き起こす](../recording/#録音済みの音声ファイルを書き起こす)

### 次の会議を予約する

用意した議事録とAIエージェントの宛先を、端末から次の会議の開始シートへ登録できます。

```bash
kikigaki-cli next add --minutes ~/work/minutes/定例.md --title "開発定例" --at 14:00 --ai 議事録 --manual スライド
kikigaki-cli next list
kikigaki-cli next remove <登録時に表示されたid>
```

| 指定 | 中身 |
| --- | --- |
| `--minutes` | 議事録の `.md` の、絶対パスか `~/` から始まるパス。まだ無いファイルでもよい |
| `--title` | 候補に出す題。省略すると議事録の見出しかファイル名 |
| `--at` | 今日の `14:00` か、`2026-10-11T14:00` のような日時 |
| `--ai` | 自動送信の宛先。設定の `[[ai]]` の `name`。省略すると「送らない」 |
| `--manual` | 手動の宛先。省略すると前回の宛先 |

予約の時刻に録音が自動で始まることはありません。
開始シートでの選び方は [録音と書き起こし](../recording/#次の会議を予約する) で説明します。

### 参加を設定せずに会話を渡す

受け取るAIエージェントにも、[Skill](#skillを導入する) を入れておきます。

1. フッターの「…」から「会話をコピー」を選びます
2. 手元のファイルを読めるAIエージェントの入力欄へ貼り付けます
3. 問いを書き足して送ります

コピーするたびに、その時点の会話の全体を渡します。

:::note
この渡し方では、AIエージェントは回答だけを返します。ファイルの変更などを頼むときは、AIエージェントの入力欄へ依頼を書いてください。
:::

## 困ったとき

### 「入力前に停止しました」で止まる

「herdrのClaude連携を確認してください」と続くときは、Claude Codeのherdr連携を入れます。
そのあとフッターの「…」の「AIセッションを作り直す」で作り直し、送り直してください。

それ以外のときは、herdrのペインで初回の承認を待っていないか確かめてください。
承認するものが無いなら、使うCLIのherdr連携が入っているか確かめてください。
詳細: [用意するもの](#用意するもの)

### herdrやCLIが見つからないと言われる

設定の `command` と `herdrCommand` に、絶対パスを書きます。

### 送れなかった

送れなかった依頼には、朱色で理由が出ます。
「再送」を押すと送り直せます。

### 接続が切れた

フッターの「…」の「AIセッションを作り直す」で作り直せます。
AIエージェントが権限の確認などで止まっているときは、herdrのペインで確認してください。

### AIエージェントが前の会話を忘れた

送信シートの「会話を最初から送り直す」を付けて送ります。

### 録音を止めた後に頼みたい

録音を止めた後は、新しい依頼を送れません。
会議の後の相談は、CLIへ直接してください。

:::caution
録音を止めると、返事が片付いた時点でAIエージェントのherdrのペインを閉じます。10分たつと、返事を待っている途中でも閉じます。
:::

[^skill]: 同じ名前のSkillが既にあるときは上書きしません。外すときは `kikigaki-cli skill uninstall` を実行します。
[^trust]: CLIの種類や作業ディレクトリ `cwd` を変えると、もう一度出ることがあります。
[^hotkey]: ほかのアプリが同じキーを使っていると登録できず、警告が出ます。書式は [設定リファレンス](../configuration/) を参照してください。
[^auto]: 3回続けて送れなかったときは、自動送信が止まります。
[^notify]: AIエージェントのCLI自身が鳴らす音は、KIKIGAKIからは止められません。
[^late]: KIKIGAKIを終了している間に届いた返事は、次の起動時に取り込みます。
