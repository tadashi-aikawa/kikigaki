CodexやClaude Codeを会議の参加者にして、議事録の作成や質問への回答を会議中に頼めるようにします。
AI参加を設定しなくても、会話をコピーして任意のAIへ渡す使い方もできます。

## しくみ

1. KIKIGAKIが、herdrの専用ペインでCodexかClaude Codeを起こします
2. 送信すると、会話の範囲と問いをそのペインのAIへ渡します
3. AIは導入したSkillに従って会話を読み、同梱の `kikigaki-cli` でKIKIGAKIへ返事を返します
4. 返事は書き起こしウィンドウに発話と並んで表示され、会議のMarkdownの `## AIとのやりとり` に残ります

AIへ送るのは、手動か自動で送信したときだけです。何がどこへ渡るかは [データの行き先](../data/) にまとめています。

## 用意するもの

- herdr
- CodexかClaude Code。どちらもAIとして参加できます
- `kikigaki-cli`。Homebrewで導入したKIKIGAKIに同梱され、PATHが通っています

KIKIGAKIをFinderなどから起動すると、普段のシェルのPATHが効きません。
そのためherdrとCLIは、PATHのほかに次の場所を順に探します。

1. `~/.local/bin`
2. `~/.local/share/mise/shims`
3. `/opt/homebrew/bin`
4. `/usr/local/bin`

それでも見つからないときは、設定の `command` と `herdrCommand` に絶対パスを書きます。

## 1. Skillを導入する

AIが会話を受け取る手順をまとめたSkillを、端末で導入します。

```bash
kikigaki-cli skill install
```

- `~/.claude/skills/kikigaki` と `~/.codex/skills/kikigaki` へ、アプリ内のSkillを指すリンクを張ります
- リンクなので、一度実行すればアプリの更新後も新しいSkillが届きます
- 同名のファイルが既にある場合は上書きしません
- 外すときは `kikigaki-cli skill uninstall` です。外すのはアプリ内のSkillを指すリンクだけです

## 2. 設定へ宛先を書く

`~/.config/kikigaki/config.toml` に `[[ai]]` を書きます。

```toml
[[ai]]
cli = "codex" # Claude Codeなら "claude"
address = "迅雷へ"
autoPrompt = "会議の決定事項と担当・期限をMarkdown議事録へ更新してください"
```

- `address` は宛名です。末尾の「へ」を除いた部分が、会議でのAIの名前になります
- 書いたら、メニューバーのメニューの「設定を再読込」で読み直します。AIの設定は会議の開始時に固定するので、次の会議から効きます

複数の宛先を書くと、送信ごとに選べます。1つ目が既定です。

```toml
[[ai]]
name = "議事録"
cli = "codex"
effort = "high"
address = "迅雷へ"
autoPrompt = "会議の決定事項と担当・期限をMarkdown議事録へ更新してください"

[[ai]]
name = "相談"
cli = "claude"
address = "ネオへ"
```

全キーは [設定リファレンス](../configuration/) を参照してください。

## 3. 初回の信頼確認

初回の送信で、herdrに「KIKIGAKI 迅雷 14:00」のような名前の専用ワークスペースができ、そこでAIが起動します。

最初の一度だけ、CLIが作業ディレクトリを信頼するかを確認します。
KIKIGAKIに「初回設定をherdrで確認してください」と出たら、herdrのペインで内容を確かめて承認してください。
承認すると、KIKIGAKIは入力の準備ができたことを確かめてから送信します。

- 作業ディレクトリの既定は `~/Library/Application Support/KIKIGAKI/ai-work/` に固定です。会議ごとに確認が出ることはありません
- CLIの種類や作業ディレクトリ(`cwd`)を変えたときは、もう一度確認が出ることがあります
- KIKIGAKIは確認ダイアログへ代わりに答えません

## 手動で頼む

フッターの左端のロボットを押し、「手動実行…」を選びます。

送信シートには、宛先・送る範囲・問い欄・作業の許可が並びます。

- ⌘Enterで送信します。EnterとShift+Enterは改行です。Escで閉じます
- 問い欄が空なら、会話の末尾でAIへ向けた声の問いを使います
    - 例: 「迅雷、さっきの案を直して」と話してから、問い欄を空のまま送る
- 問い欄に書いた文は、あなたの明示的な依頼として送ります
- 問い欄には、宛先の `autoPrompt` が初期値として入ります
- 送る範囲は、送信を押した時点までの会話です。押した後に話した内容は含みません
- 1回目は会話の全体を、2回目以降は前回から変わった部分を送ります。話者名の変更や統合による訂正も、この差分で伝わります
- 話者名と文字は、認識の誤りを含んだまま渡ります

返事を待っている間は、同じ宛先へ追加で送れません。
別の宛先へは同時に送れます。

AIが前の会話を失ったと返してきたときは、シートの「会話を最初から送り直す」を付けて送ります。

### 作業の許可

シートの「作業を許可する(ファイル編集・コマンド実行)」で、AIに作業まで任せるかを決めます。

| 状態 | AIがすること |
| --- | --- |
| オン | 声での依頼でも、ファイル編集やコマンド実行などの作業に入ってよい |
| オフ | 回答と提案まで。作業には入らない |

- 初期値は設定の `allowWork` で、既定はオンです
- 会議中に変えると、その会議の次の送信にも引き継ぎます。新しい録音で設定の値に戻ります
- 実際の操作を承認するかは、CLIの権限設定と、herdrのペインでの承認で決まります。この設定でCLIの権限は変わりません

## 返事を読む

AIの返事は、発話と同じ形の行で表示します。

- アバター・名前・時刻・本文(Markdown)と、本文の下にCLIとモデル・作業ディレクトリの表記が出ます
- 名前の横のチップは、手動の依頼なら「AI」、自動送信なら「自動」です
- 返事を待つ間は、進み具合を1行とバーで表示します。「取消」は待つのをやめるだけで、AIの処理は止めません
- 通知音は、設定の `notifySound = true` のときだけ鳴ります

### 確認質問に返答する

AIが確認を返してきた行には、朱の「要返答」が付きます。

1. その行の「返答する」を押します
2. 開いたシートに返答を書いて、⌘Enterで送ります

返答は、確認してきたのと同じ宛先へ送ります。

### 送れなかったとき

送れなかった依頼は、朱の帯で理由を表示します。
帯の「再送」から、同じシートで送り直せます。

### 会議のMarkdownに残るもの

```markdown
## 書き起こし

- [14:05:00] 田中: 迅雷、さっきの案を直して。
- [14:05:03] AIへ #1 → AIとのやりとり
- [14:06:02] AIから #1 → AIとのやりとり

## AIとのやりとり

### AI #1

- 送信: 2026-09-06 14:05:03 +09:00
- 宛先: 迅雷
- 送信文: 「迅雷、さっきの案を直して。」
- 作業許可: あり
- 返事: 2026-09-06 14:06:02 +09:00

#### 返事

修正しました。
```

録音を止めた後に届いた返事も、同じ会議のMarkdownへ保存します。
KIKIGAKIを終了している間に届いた返事は、次の起動時に取り込みます。

## 自動で送る

数分おきに会話の差分を送り、議事録を書き進めてもらえます。

### 録音中に始める

ロボットを押し、「自動実行…」を選びます。

| 項目 | 内容 |
| --- | --- |
| 宛先 | 送る相手 |
| プロンプト | 毎回送る依頼。宛先の `autoPrompt` が初期値 |
| 間隔 | 1・2・3・5・10分から選ぶ。既定は3分 |
| 作業を許可する | 手動と同じ意味 |
| 録音停止時に最後の1回を送る | 既定はオン |

⌘Enterで開始します。

### 録音の開始と同時に始める

録音開始シートの「自動送信」の行で宛先を選ぶと、録音と同時に自動送信が始まります。

- 設定で `autoStart = true` を付けた宛先が、この行の既定になります
- 「送らない」を選んだ会議では、`autoStart` があっても始めません

### 自動送信の動き方

- 開始した直後に1回、送るかを判定します
- 会話に変わりがなければ送りません
- 返事を待っている間と、答えていない確認質問がある間は送りません
- 3回続けて失敗すると止まります
- 録音を止めると、保存が終わった後に、変わった部分があれば最後の1回を送ります

自動送信の間、ロボットは朱の輪郭になり、次の送信までの残り時間を `2:30` の形で表示します。
送った依頼の返事を待つ間は、手動・自動とも朱の塗りに変わります。

- 「今すぐ送る」: 次の時刻を待たずに判定して送ります
- 「自動実行解除」: 自動送信を止めます
- 宛先や間隔を変えるときは、いったん解除してから「自動実行…」で入れ直します

## 録音を止めた後

- 新しい依頼は送れません。「手動実行…」「返答する」「再送」は使えなくなります
- 待っている返事が届くなどして片付くと、KIKIGAKIがherdrのペインを閉じます。停止から10分たつと、待たずに閉じます
- ペインを閉じられなかったときは警告が出ます。herdrで手で閉じてください
- 会議の後の相談は、CLIへ直接してください

## 接続が切れたとき

- 録音中にAIのペインとの接続が切れると、ロボットのメニューに「AIセッションを作り直す」が出ます。新しいセッションへ会話の全体を送り直します
- AIが権限の確認などで止まっている間は送りません。herdrのペインで確認してください

## AI参加を設定せずに会話を渡す

フッターの「…」から「会話をコピー」を選ぶと、会話を任意のAIへ渡すための文をクリップボードへ書きます。
手元のファイルを読めるAIの入力欄へ貼り付けて使います。

- 毎回、その時点の会話の全体を渡します
- 会話の本文はクリップボードに入れません。保存先の `.kikigaki-context/` に会話を書いたファイルを作り、その場所を渡します
- 半透明の行は含めます。「聞き取り中…」の行と、小さな声として除外した行は含めません
- 議事録を表示していれば、その議事録の場所も渡します
- 受け取る側にもSkillが要ります。「1. Skillを導入する」を済ませておいてください
- 問いは、貼り付けた後に書き足すか、会話の末尾で声にしておきます
- このコピーでは、声の問いには回答だけを返します。ファイルの変更などを頼むときは、AIの入力欄で明示的に依頼してください
