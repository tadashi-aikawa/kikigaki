# 和紙の帳面: GUI刷新と話者操作の仕様

採用ロゴ「会話フクロウ」に合わせて書き起こしウィンドウの世界観を作り直し、未確定文の表示・実時刻・アバター・クリック改名・話者候補を足す。タダシとの認識合わせ(2026-09-05)で確定した決定と、実装へ渡す仕様をまとめる。

## 決定事項

- 基調は**和紙の帳面**。生成りの地に墨の文字。ダークモードは作らない
- 見た目は**実寸モックを先に承認**してから実装する
- 未確定(暫定)の文字起こしは**話者を出さず薄字**で示す。ただし直前の話者の発言の続きに見えてはいけない
- 文字が確定しても話者判定が凍結前(8秒以内)の行は、確定行と**区別しない**
- 画面の時刻は**実時刻**を主にし、経過はホバーのツールチップに退避する
- 保存するMarkdownとAI受け渡しの会話ファイルの行も**実時刻**にする。理由: Markdownを渡して議事録を作らせるとき、会議の時刻が読めることが大きい
- アバターと話者候補は **`config.toml` の話者一覧**から取る。画像は**ローカルパスとURL**の両方を受ける。入力履歴は持たない
- 声による話者の自動推論は**やらない**(今のところは)
- 話者名の変更は**ログの話者名かアバターのクリック**のみ。右上の「話者名…」ボタンとシートは外す
- 変更は**枡(スロット)単位**。行単位の付け替えは含めない

## 進め方

1. **段1: モック** — ウィンドウ全体の実寸モックを作り、タダシの承認を得る(下記「モック」)
2. **段2: 描画の土台** — 世界観の基調、未確定行、実時刻(画面とMarkdown)
3. **段3: 話者台帳** — `config.toml` の話者一覧、アバター、クリック改名、候補

段2・段3はそれぞれ1コミットにまとめる(タダシとのやりとりで生じた手直しも同じコミットへ統合する)。各段で、書き手と異なるモデルのレビュー(Fable 5.1)と、迅雷本人の受け入れテストを通す。

## 世界観

### パレット

ロゴから実測した色を基準にする。実装では名前付きの定数にまとめ、直書きしない。

| 名前 | 色 | 用途 |
|---|---|---|
| 生成り | `#F5EAD9` | 地(本文の紙面) |
| 和紙の影 | 生成りより一段暗い生成り系 | ヘッダー・フッターの面、区切り |
| 墨 | `#221F1C` | 本文の文字 |
| 薄墨 | 墨の低コントラスト版 | 時刻・補助文・暫定文 |
| 朱 | `#AA1405` | 録音中の印、話者Aの点睛、主ボタン |
| 明朱 | `#CF321F` | 朱のホバー・強調 |
| 金 | `#E09C3C` | 話者Bの点睛、保存済みなどの落ち着いた成功表示 |

朱は面で使わない。**録音中の印と点睛(アバターの縁・イニシャル丸の地)と主ボタンに絞る**。KOKUKOKUの「朱は警告と点睛のみ」の掟と同じ理屈で、朱が増えると録音中の印が埋もれる。

話者A〜Dのイニシャル丸の地の色は、朱・金に加えて墨系と青緑系などの2色を足して4色にする。生成りの地で見分けがつき、朱・金と喧嘩しないことをモックで確認する。

### モチーフとフォント

- 発話1行は「アバター+名前+時刻」の見出しと本文の2段。吹き出しの枠線は描かない(1画面に数十行並ぶと騒がしい)。ロゴの吹き出しは、アバター無し時のイニシャル丸と、未確定行の印に控えめに使う
- 本文は可読性優先でシステムフォント(ヒラギノ角ゴ)。見出しの名前もシステムフォント。明朝は使わない。ウィンドウ表題や状態表示など**文字が少ない箇所だけ**、帳面らしさのために字間や太さで表情を付けてよい
- ヘッダー(録音操作)とフッター(AIへ渡す会話)は現行の配置と機能を保つ。色と余白だけ世界観に揃える。ボタンは標準の `NSButton` を使い、主ボタン(会話をコピー、録音開始)だけ朱の塗りにする

## ログの表示

### 行の構造

```
[アバター 24pt]  田中  14:32          ← 見出し: 名前は墨の太字、時刻は薄墨の等幅数字
                 では次の議題、来期の予算配分に移ります。   ← 本文 15pt、行間は現行と同じ
```

- アバターは正円で直径24pt。画像があればそれを丸く切り、無ければ枡の色の地にイニシャル1文字(名前の先頭1文字。既定名「話者A」なら「A」)
- 時刻は実時刻 `HH:MM`。ホバーで経過 `mm:ss` をツールチップ表示
- 話者名とアバターはクリックできる。ホバーで下線か薄い地を出し、クリックできることを示す(下記「クリック改名」)
- 話者なし(`speaker == nil`)の行は「?」のイニシャル丸に薄墨の地
- 「── 次にコピーする範囲 ──」の区切り、最新の発言へのボタン、末尾追従のスクロールは現行どおり動く

### 未確定(暫定)行

- 暫定トークンの本文は、確定行の後に**1つの独立した行**として置く。見出しの位置には話者名でなく「聞き取り中…」の薄墨のラベルを置き、アバターの位置には点線の丸(吹き出しの輪郭)を描く
- 本文は薄墨の斜体。確定行との間隔は通常の行間隔と同じにし、直前の行の続きに見えないよう、ラベルと点線の丸で**別の行**であることを示す
- 確定した時点で、通常の話者付き行へ昇格する(暫定行は消え、確定行が増える)
- 暫定行の中では話者を出さない。文字が確定しているが話者凍結前の行は、確定行と同じ見た目

暫定と確定の切り分けは `AppleTranscriber.snapshot()` の `finalCount` を使う。話者の突き合わせ(`Aligner.speakers` と `SpeakerFreeze`)は現行どおり全トークンで行い、表示へ渡す直前に `finalCount` で分ける。

- 確定行: 先頭 `finalCount` 個のトークンから `Aligner.utterances` で作る
- 暫定本文: `finalCount` 以降のトークンの文字列を連結する
- `SessionSnapshot` に暫定本文を持たせる(例: `tentativeText: String?`)。停止後は常に空

ロジックの変更は `MeetingSession.makeConsumer` と `SessionSnapshot` に限る。`Aligner`・`SpeakerFreeze`・相槌省略・AI受け渡しの判定は変えない。

### 実時刻

- 発話の実時刻 = 会議開始の実時刻 + 音声上の時刻 + その時点までの一時停止の合計
- 一時停止・再開のたびに「音声時刻→実時刻のずれ」を記録する対応表を `MeetingSession` が持ち、`SessionSnapshot` へ渡す。純粋な変換関数は Core に置いてユニットテストする
- `--replay` は再生開始の実時刻を開始時刻とする(現行の `startedAt` と同じ)

### Markdownと会話ファイルの行形式

`TranscriptRenderer.line` の時刻を経過から実時刻へ変える。

```
- [14:32:05] 田中: では次の議題、来期の予算配分に移ります。
```

- 秒まで書く。理由: 同じ分に複数の発話があり、経過秒の粒度を落とさない
- `MeetingMarkdown.Meeting` に一時停止の対応表(または各発話の実時刻)を渡せるようにし、`duration` は現行どおり音声の長さ
- AI受け渡しの会話ファイル(`AIHandoff`)は同じ `TranscriptRenderer.line` を使うので自動的に揃う。`skills/kikigaki/SKILL.md` と `docs/ai-handoff.md` に時刻の形式を書いている箇所があれば更新する
- 既存の保存済みMarkdownは変換しない。形式が変わる旨を `CLAUDE.md` の保存形式の説明に1行足す
- `KIKIGAKI_DEBUG_LIVE` などの診断出力は変えなくてよい

## 話者台帳(config.toml)

```toml
# 話者の一覧。名前の候補とアバターに使う。省略可
[[speakers]]
name = "田中"
avatar = "~/Pictures/avatars/tanaka.png"

[[speakers]]
name = "迅雷"
avatar = "https://example.com/jinrai.webp"
```

- `name` は必須。空・重複は設定エラーとして既存の `ConfigError.invalid` で報告する
- `avatar` は省略可。ローカルパスは `~` を展開する。`http://` `https://` のURLは起動時または初回表示時に1回取得し、`~/Library/Caches/kikigaki/avatars/` へキャッシュする。取得失敗・読めない画像・存在しないパスはログに出してイニシャル丸で描く。UIを止めない(取得は非同期)
- 対応形式は `NSImage` が読めるもの(png・jpg・webp・heic 等)
- 設定の再読込のタイミングは現行どおり(次の会議から)。ただし台帳は会議に属さないので、再読込後の次の描画から反映してよい
- 表示名は枡ごとに持つ現行の `SpeakerNames` のまま。台帳の `name` と一致する名前が枡に付いていればアバターが出る。台帳に無い自由入力の名前はイニシャル丸

## クリック改名

- ログの話者名かアバターをクリックすると、その位置に `NSPopover` が開く
- ポップオーバーの中身
    - 台帳の名前の一覧(クリックで即反映)。既に別の枡に付いている名前は薄く表示し、選ぶと元の枡から外れる旨を示すか、選択不可にする(モックで決める)
    - 自由入力欄(Return で反映、Esc で閉じる。現行のシートと同じくコピー・ペーストが効くこと)
    - 「既定に戻す」(話者A などの既定名へ)
- 反映は `MeetingSession.rename(slot:to:)` を使い、同じ枡の全行と、停止後なら保存も更新する。現行の4枡一括の `rename(names:)` と `SpeakerNamesSheet` は削除する
- 録音中のライブ更新でポップオーバーが閉じたり選択が飛んだりしないこと
- 新しい会議の開始で枡の名前が既定に戻る現行の挙動は保つ(Sortformer の枡は会議ごとに振り直される)

## 受け入れ観点(本人が確認する)

- `--replay` で既存のサンプル音声を流し、録音中に未確定行が話者なしで出て、確定で話者付き行へ変わる
- 一時停止を挟んだ録音で、再開後の行の実時刻が壁時計とずれない
- 保存されたMarkdownの行が `[HH:MM:SS]` で、開始時刻と整合する。会話をコピーしたAI受け渡しの範囲が現行どおり働く
- `config.toml` に台帳を書き、ローカルパスとURLの両方のアバターが出る。壊れたパス・URLでもアプリが止まらずイニシャル丸になる
- 話者名クリック→候補選択・自由入力・既定に戻すの3操作が、録音中と停止後の両方で全行と保存に反映される
- 「話者名…」ボタンが無く、ヘッダー・フッターの他の操作は現行どおり動く
- 世界観がモックと一致する
