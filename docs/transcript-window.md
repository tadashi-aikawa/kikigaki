# 書き起こしウィンドウ

会議の発話を並べる書き起こしウィンドウの見た目と操作の仕様。配色は `Sources/Kikigaki/Washi.swift`、行は `TranscriptRow.swift`、全体は `TranscriptWindow.swift` が持つ。

- 発話行の確定前後の半透明表示は [発話の確定表示](utterance-progress.md) が正本
- 手入力欄は [手入力の設計](typed-entry.md)
- 右の議事録ペインは [議事録ペイン](minutes-pane.md)
- 話者の手動統合は [話者の手動統合](speaker-mapping.md)

## 世界観

基調は**和紙の帳面**。生成りの地に墨の文字で、ダークモードは作らない。採用ロゴ「会話フクロウ」に世界観を合わせる。

### パレット

ロゴから実測した色を基準にし、名前付きの定数を `Washi` に集める。直書きしない。

| 名前 | 色 | 用途 |
|---|---|---|
| 生成り `paper` | `#F5EAD9` | 地(本文の紙面) |
| 和紙の影 `shade` | `#EDE0CD` | ヘッダー・フッターの面、更新時の点灯 |
| 罫 `rule` | `#D5C6B1` | 区切り線、無効時の輪郭 |
| 墨 `ink` | `#221F1C` | 本文の文字 |
| 薄墨 `muted` | `#6B6157` | 時刻・補助文・未確定行の破線 |
| 朱 `red` | `#AA1405` | 録音中の印、主ボタン、停止の輪郭、話者Dの地 |
| 明朱 `brightRed` | `#CF321F` | 主ボタンのホバー |
| 金 `gold` | `#C4801F` | 話者Bの地。文字は墨 |
| 文字用の金 `goldInk` | `#8A5A12` | 一時停止・再開の文字と輪郭 |

朱は面で使う場面を絞る。録音中の印と主ボタン、話者Dのアバターに限る。朱が増えると録音中の印が埋もれるため。録音中の印は直径8〜9pt。「保存済み」は印を付けず文字だけにする。

話者A〜Dのイニシャル丸の地は、青緑 `#3E706C`・金 `#C4801F`・墨系 `#514A43`・朱の順にする。E〜Hは同じ4色を循環させ、記号と名前で見分ける。未定義の枡も不明話者の色にはしない。

- 朱を先頭にしない理由: 最もよく話す話者Aに朱を使うと、1人で話す会議では左の列が朱で埋まり、録音中の印が埋もれる
- 墨系を先頭にしない理由: 不明話者の薄墨と手入力の墨に並び、見分けにくい
- 枡の数は `SpeakerNames.slotCount`(8)を参照し、画面側に数を直書きしない。Markdownの話者一覧は発言に現れた枡から生成する

AI参加者は枡の色とは別に固定の紫 `#5B3E7A` を使う。人と同色にならないようにするためで、宛先が複数あってもこの1色のままにし、名前で区別する。

### モチーフとフォント

- 会話フクロウのロゴをヘッダー左端に26ptで置く。状態表示との間に余白と細い区切りを設け、9ptの録音中の印をロゴに接続して見せない。録音前の空状態では本文中央に96ptのロゴと案内文を置く。大きなロゴは会話表示中には出さない。元画像は `Resources/kikigaki.png`、配布アプリでは同じロゴの同梱 `kikigaki.icns` を使う。詳細は [ロゴの管理](logo.md)
- 本文は可読性優先でシステムフォント(ヒラギノ角ゴ)。見出しの名前もシステムフォント。明朝は使わない
- 発話全体を囲む吹き出しの枠線は描かない。1画面に数十行並ぶと騒がしいため。ロゴの吹き出しは画像とイニシャルのアバターに使い、左下の尾で輪郭を揃える
- ヘッダー右上はSF Symbolsのアイコンボタンにし、開始・停止・一時停止・再開・Markdownを開くを状態に応じて切り替える。文字ラベルはツールチップとアクセシビリティラベルにする
- 主ボタンは1画面に1つ。朱の塗りは録音の開始に使い、前の会議を表示中の「新しい録音」も同じ塗りにする

## 行の構造

```
[アバター 24pt]  田中  14:32:05          ← 見出し: 名前は墨の太字、時刻は薄墨の等幅数字
                 では次の議題、来期の予算配分に移ります。   ← 本文 15pt、行間4pt
```

- アバターは直径24ptの円を本体に、左下の小さな尾を添えた吹き出し形。画像も同じ外形で切り抜く。画像が無ければ枡の色の地に名前の先頭1文字を出し、既定名「話者A」なら「A」とする
- 話者判別を使わない会議は、全員共通の「発言」とマイク記号で示す。詳細は [話者判別の切替](diarization-toggle.md)
- 話者なし(`speaker == nil`)の行は「?」のイニシャル丸に薄墨の地
- 時刻は実時刻 `HH:MM:SS`。ホバーで会話の位置の経過 `mm:ss` をツールチップ表示する。ヘッダーの録音長は経過 `mm:ss`
- ヘッダーの録音状態の直後に、薄い小文字で記録範囲を実時刻で出す。録音中は開始時刻と `〜`、停止後は開始時刻〜終了時刻
- 話者名とアバターはクリックできる。ホバーで下線か薄い地を出す
- 発話の実時刻は「会議開始の実時刻 + 音声上の時刻 + その時点までの一時停止の合計」。一時停止・再開のたびに音声時刻と実時刻のずれを記録する対応表を `MeetingSession` が持つ
- 保存するMarkdownとAI受け渡しの会話ファイルの行も同じ実時刻で、`[HH:MM:SS] 話者名: 本文` の形。フッターにコピー範囲の表示は無く、「会話をコピー」は「…」メニューから全体を渡す
- 末尾追従のスクロールと「最新の発言」へのボタンがある

### 未確定(暫定)行

- 暫定トークンの本文は、通常行の後に**1つの独立した行**として置く。見出しの位置には話者名でなく「聞き取り中…」を置き、アバターの位置には点線の丸を描く。線幅は約1.75ptの薄墨
- 行全体を不透明度60%にする。合成斜体と薄い帯は使わない
- 暫定行の中では話者を出さない。時刻も出さない
- 確定した時点で、通常の話者付き行へ昇格する(暫定行は消え、確定行が増える)
- 暫定行はコピー範囲に含めない

暫定と確定の切り分けは `AppleTranscriber.snapshot()` の `finalCount` を使う。話者の突き合わせは全トークンで行い、表示へ渡す直前に分ける。暫定本文は `SessionSnapshot.tentativeText` が持ち、停止後は常に空。

### 更新のトランジション

- 本文は行ビュー内の選択可能な `NSTextField` で表示する。行をまたぐ選択は扱わない。発言開始位置と同時刻の出現順をキーにビューを再利用し、統合で不要になった行は即時削除する
- 行ビューは全行ぶん持つが、画面に載せるのは見えている範囲の上下1200pt(見えている高さが大きければその高さ)の中だけ。長い会議でもスクロールの1コマが行数に比例して重くならない
    - 限界: 行の本文で選択した範囲は、その行が載せる範囲の外へ出ると解除される
- 録音中に追加された確定行は0.25秒でフェードインする。本文か話者が変わった既存行は、和紙の影の地を1.25秒で消す。停止時の再判定も同時に点灯する
- 暫定行は同じビューの本文を更新する。追加の文字にフェードや点灯は付けず、途中の書き換えも即時反映する
- macOSの「視差効果を減らす」が有効なら瞬時表示にする。設定が途中で有効になったときも進行中のアニメーションを終了する
- 末尾追従、最新の発言への移動を保つ。上方の行が折り返しで伸びても、現在読んでいる行の画面上の位置を維持する

## 話者台帳とクリック改名

話者名の候補とアバターは設定ファイルの `[[speakers]]` から取る。書式と画像の扱いは [設定リファレンス](config.md) を参照する。台帳に無い自由入力の名前はイニシャル丸で表示する。声による話者の自動推論はしない。

ログの話者名かアバターをクリックすると、その位置に `NSPopover` が開く。

- 台帳の名前の一覧。クリックで即反映して閉じる。各候補に20〜22ptのアバターを表示し、画像が無ければイニシャルにする。既に別の枡に付いている名前は薄く表示して選択不可とし、「話者Bで使用中」を添える
- 自由入力欄。現在の名前を入れ、開いた瞬間に全選択する。Returnで反映し、Escで閉じる
- 「既定に戻す」。話者Aなどの既定名へ戻す

変更は枡単位で、`MeetingSession.rename(slot:to:)` が同じ枡の全行と、停止後なら保存も更新する。行単位の付け替えは無い。新しい会議の開始で枡の名前は既定に戻る。話者判別の出力は会議ごとに枡が振り直されるため。

## フッターの「…」メニュー

「会話をコピー」が常にあり、押すたびに記録している会話の全体と表示中の議事録の参照を渡す。契約は [会議中の会話をAIへ渡す](ai-handoff.md)。

AIの項目は使える時だけ区切り線の下に出す。停止後などに押せない項目を並べて読み飛ばさせないため。

- 「ペインを開く」: 開けるペインがある時だけ
- 「保存を再試行」: AI記録の保存に失敗した時だけ

「今すぐ送る」「自動実行…」「自動実行解除」「手動実行…」「AIセッションを作り直す」はフッター左端のロボットのメニューに置く。操作は [AIへの定期自動送信](ai-scheduled.md) を参照する。

前の会議の要返答を案内する項目と、過去会議のAIの返事を開く窓は置かない。停止後の会議には返答できず、窓から解消できない案内が出続けるため。停止後の扱いは [AI参加者の設計](ai-participant.md#録音停止後の後片付け) を参照する。

## 最前面への固定

フッターのピンボタンで、書き起こしウィンドウを通常表示と最前面固定に切り替える。固定中は朱色の塗りつぶしたピンになり、ほかのアプリを操作しても通常のウィンドウより手前に残る。

既定はOFF。アプリ起動中は録音状態の更新やウィンドウの開き直しでも保持し、アプリを再起動するとOFFへ戻る。閉じる・最小化の操作は通常どおり使用できる。macOSのフローティングウィンドウのレベルを使い、別のSpaceや他アプリのフルスクリーンへ追従させる機能は追加しない。

## ウィンドウの横幅

最小幅は420pt。幅600pt未満では録音開始・停止・一時停止・再開のボタンをアイコンのみで表示し、ホバーとアクセシビリティラベルで操作名を確認できる。600pt以上へ戻すと文字付きに戻る。議事録ペインを開いているあいだは、幅を左ペインの幅で判定する。初期幅は600ptで、高さの下限は460pt。

狭い幅では本文の折り返しが増える。開始・終了の実時刻が入りきらない場合は中央を省略し、ホバーで全体を表示する。

録音操作は高さ32pt。文字付きでは開始・停止・一時停止・再開をすべて120ptに揃え、同じボタンが状態の変化で伸縮しない。アイコンの枠は16pt、文字との間隔は8ptで、最長ラベルでも左右に14pt以上の余白を残す。アイコンのみでは幅34ptの中央に置く。

一時停止・再開は文字用の暗い金、停止は朱の文字・アイコン・輪郭で表示する。輪郭ボタンはホバー時に同色14%、押下時に22%の地を添える。主ボタンはホバー時に明るい朱、押下時に暗い朱へ変える。無効時は薄墨の文字・アイコンと罫色の輪郭にし、地を足さない。状態チップと話者の塗り用の金は変えない。

輪郭ボタンのホバー・押下中は文字とアイコンをさらに暗い金・朱にし、濃くなった地とのコントラストを保つ。

待機中で前の会議を共有できない「録音を開始」と、保存後の「新しい録音」は、どちらも朱の塗りの主ボタンにする。
