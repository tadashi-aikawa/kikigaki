# 録音開始シート

「録音を開始」を押すと、その会議だけの指定をまとめて決めるシートが出る。指定を終えてから録音が始まる。

## 目的

会議ごとに変えたいものは、システム音声・話者判別・小音量除外・議事録・自動送信の5つに集まる。以前はそれぞれ別の場所(人型ポップオーバー・右ペインのパス欄・ロボットのシート)にあり、録音を始めてから設定し直すことになっていた。始める前に1枚へ集める。

設定ファイルに書くもの(保存先・話者台帳・CLIの種類)はここへ置かない。会議ごとに変える値ではないうえ、シートから書き戻すと設定ファイルの正本が2つになる。

## 出す場面と決めるもの

シートは `MeetingSession.start` の**前**に出す。取消は録音を始めないので、会議の巻き戻しは要らない。

| 行 | 決めるもの | 既定値 |
|---|---|---|
| システム音声 | 「自動」「取り込む」「取り込まない」 | 前回の選択。初回は自動 |
| マイク | いまの既定入力の装置名。表示だけで操作なし | OSの既定入力 |
| 話者判別 | 「区別する(最大8人)」/「区別しない」 | 前回の選択(UserDefaults) |
| 小音量除外 | ON/OFFのスイッチ。しきい値は文字で見せるだけで、調整は録音中の「話者」ポップアップに残す | 次回設定の値 |
| 議事録 | 絶対パス。履歴・「ファイルを選ぶ…」・`.md` のドロップから入れる | 空欄(指定なし) |
| 自動送信 | 宛先・間隔・プロンプト・作業許可・最後の1回 | 宛先は `autoStart` のプロファイル、無ければ「送らない」 |

`[[ai]]` が無ければ自動送信の行ごと出さない。宛先メニューの各行はアバター・名前・CLIとモデルとeffort・プロンプトの先頭で、同じ名前と型のプロファイルを依頼の中身で見分けられるようにする。プロンプトは畳まず、幅いっぱいの欄に数行ぶん見せてそのまま書き換える。

**説明文は置かない。** 「録音を始めると変えられません」「開始と同時に右のペインへ表示します」のような補足は、毎回読まされる割に決めるものを増やさない。読めない議事録の指定に出す理由の1行だけを例外にする。

シートの幅は640pt。既定のウィンドウ(600pt)より広いが、議事録の絶対パスを縮めずに読めることを優先した。

- 書き起こしウィンドウに付くシートとして表示する。
  - 位置: `parent.beginSheet` によるAppKitの標準配置を使う。
  - 高さ: 開く前に全宛先の詳細と議事録のエラー行を測り、最大の高さを確保する。候補・「指定しない」・宛先・議事録の編集やエラー表示で窓の高さを変えない。
  - スクロール: 画面の可視領域から上下20ptを引いた高さを上限にする。収まらない本文はスクロールする。プロンプト欄は100pt固定で、長文は欄内をスクロールする。
  - 自動送信: 「送らない」でも詳細を畳まず、薄くして操作不可にする。宛先を戻すと下書きと操作を復元する。
  - 取消: 親ウィンドウのシート外クリックは「取消」と同じ扱いで閉じる。クリックを親のボタンへ流さない。ファイル選択パネルが付いている間は外側クリックで閉じない。
  - 再表示: 録音ボタンを再度押すと同じシートへ焦点を戻す。ファイル選択中はパネルへ戻す。

⏎ と ⌘⏎ のどちらでも開始する。プロンプト欄に焦点がある間だけ、素の⏎は改行になる。Escと「取消」は何も始めない。

## 次の会議

同梱CLIの `kikigaki-cli next add` で予約を登録する。開始シートの最上段に「次の会議」行を出す。

- 候補は時刻の早い順に並ぶ。
  - 順序: 時刻が無いものは登録順で後ろに並ぶ。同時刻も登録順にする。
  - 上限: 先頭3件だけを表示する。開く時点で0件なら行ごと出さない。
- 各候補は2段で表示する。
  - 操作: ラジオの丸・題・2段目・行内の余白をクリックして選べる。
  - 1段目: 時刻と題を13ptの墨で表示する。題を省略した場合は議事録の先頭64KiB内の `# ` 見出しを使う。見出しも無ければファイル名にする。
  - 2段目: 宛先のアバター・宛先名・ファイル名を11ptの薄墨で表示する。
  - 例外: 設定に無い宛先は金色で「設定にありません」と示し、その候補では「送らない」にする。議事録ファイルが無ければ金色で「見つかりません」を添える。
- 候補の行へマウスを乗せると、右端に薄墨の×を表示する。
  - 見え方: 既存のクリアボタンと同じ `xmark.circle.fill` を16ptの枠に置く。乗せていない間は隠す。
  - 操作: ツールチップと読み上げは「この予約を削除」。×を押しても行の選択は起こさない。
  - 削除: 確認ダイアログを出さず、`NextMeetingStore.remove(id)` で予約のファイルだけを消す。議事録のファイルには触らない。
  - 選択: 選択中の候補を消したら残りの先頭を選び、議事録欄と宛先を埋め直す。残りが無ければ「指定しない」を選ぶ。
  - 表示: 消した候補をシートから取り除く。最後の1件を消しても「次の会議」行と「指定しない」は残す。開いているシートの高さは変えない。
  - 例外: 店から削除できなくてもシートからは取り除き、診断ログに残す。画面に説明文は出さない。
- 開いた時点で先頭を選ぶ。
  - 反映: 議事録欄と自動送信の宛先を予約の値で埋める。宛先省略は「送らない」にする。ほかの値は従来の既定を使う。
  - 焦点: 「開始」に置く。朱の面に青いフォーカスリングは出さず、キーボードでの焦点移動は保つ。
- 最後の選択肢は「指定しない」にする。
  - 反映: 議事録欄を空にし、宛先を `autoStart` のプロファイルか「送らない」へ戻す。
  - 余白: 仕切り線まで10ptを確保する。
- 下の欄の手編集は、その録音の指定として扱う。
  - 保存: 予約や設定ファイルへ書き戻さない。
- 開始シートで選んだ予約1件だけをidで消費する。
  - 条件: 録音開始に成功し、開始時の議事録パスが選んだ予約と一致している場合に限る。
  - 保持: 同じ議事録を指す別の予約は残す。議事録欄を別のパスへ変えた場合も予約は残す。
  - 例外: 「指定しない」で開始した場合、取消、開始失敗では削除しない。
- 登録から24時間経った予約は、シートを開くときに削除する。
  - 基準: 予定時刻ではなく登録時刻から数える。
- 説明文と候補管理画面は置かない。
- 時刻からの自動開始とカレンダー連携は行わない。

登録の書式と保存形式は [同梱CLI](ai-participant.md#同梱cli) を参照する。

## 値の行き先

「マイク」行はシステム音声の直下に置く。装置名の値だけを出す。

- 追従: 開いている間は「自動」と同じ0.25秒のタイマーで既定入力の名前を読み直す。
- 高さ: 1行のまま末尾を省略する。長い名前への切替でも窓の高さを変えない。全文はツールチップで読める。
- 未接続: `接続されていません` と出す。
- 録音中: 既定入力の切替にも追従する。詳細は [マイク単独録音中の既定入力の切替](system-audio.md#マイク単独録音中の既定入力の切替)。

シートが決めた値はこの録音にだけ効き、設定ファイルへは書き戻さない。

- **システム音声**: 開始時に選択を専用UserDefaultsキー `KikigakiSystemAudioMode` へ保存する。取消では保存しない。
  - 判定: 「自動」の括弧内はシートが開いている間、既定の出力に追従する。開始を押した時点の取り込み有無を会議へ固定する。
  - 詳細: [システム音声の取り込み](system-audio.md)
- **話者判別**: 開始時に `setDiarizationEnabled` を呼ぶ。次回の既定にもなる。取消した選択は残らない
- **小音量除外**: 開始時に `setAudioExclusion` へON/OFFだけを重ねる。しきい値は次回設定のまま。こちらも次回の既定になる
- **議事録**: `MeetingSession.prepareMinutes` で預ける。**この場では表示中の会議のstoreへ当てない。** 停止後も前の会議のMarkdownは残っているので、いま当てると前の会議の議事録になってしまう。`start` が会議を切り替える時点で待機指定へ移し、`previewMinutesStore` が新しい会議へ引き継ぐ。指定があれば開始と同時に右ペインを開く
- **自動送信**: `MeetingSession.pendingAutomaticSchedule` へ枠と `AIScheduleOptions` を預け、`startAutomaticSchedule` が設定の `autoStart` の代わりに使う。**「送らない」を選んだ会議では、設定に `autoStart` があっても始めない。** 指定は1回だけ効き、次の録音へは持ち越さない

宛先を選び直すと、その宛先の `autoPrompt`・`autoIntervalMinutes`・`allowWork` を初期値として出す。シートの中で書き換えた文面と間隔は宛先ごとに覚え、選び直して戻れば元に戻る。

## 出さない場面

- **replayと検証**: シートを出さず、前回の値と `KIKIGAKI_DEBUG_*` の指定で同じ開始経路を通す。`pendingAutomaticSchedule` は未設定のままなので、設定の `autoStart` が従来どおり効く
  - システム音声: 実デバイスは開かない。`KIKIGAKI_DEBUG_REPLAY_SYSTEM` を指定した場合だけ、2本のファイルを混ぜる。

## 決めなかったこと

- **議事録欄の初期値に前回のパスを入れない。** 議事録は会議ごとに別のファイルになるほうが多く、前回のパスが残っていると気づかないまま前の会議の議事録を上書きさせてしまう。1クリックで選べる履歴があれば足りる
- **「前の会議」の行と停止後ヘッダーの保存先表示は出さない。** 設定ではない情報を設定の並びへ混ぜない
- **グローバルショートカットは廃止した。** 開始が対話操作になったので、キーだけで始められる意味が無くなった
- **`kikigaki://` は廃止した。** 代わりに `kikigaki-cli next add` で予約する。
- **録音の取り止め(`abandon`)も外した。** 開始前に取消せるので、始まった会議を保存せず巻き戻す経路が要らなくなった

## 検証

- `StartSheetTests`: 録音開始シートの表示と操作
  - 設定: システム音声の3択と自動判定の更新、AI区画の有無、宛先の既定と下書きの復元、「送らない」の無効表示、議事録の検証とドロップ
  - 高さ: 候補・「指定しない」・全宛先・議事録エラー・長いプロンプトで窓の高さと上端を保つ。画面に収まらない本文はスクロールする。
  - 取消: 外側クリックで録音を始めずに閉じる。ファイル選択パネル中は閉じない。
- `StartSheetScheduleTests`: シートの値での自動送信、「送らない」で設定の `autoStart` を使わないこと、議事録を次の会議へ持ち越すこと
- `MicrophoneSwitchUITests`: マイク名の表示とタイマー追従、長い名前でも高さを保つこと
- 見た目は `KIKIGAKI_START_SHEET_CAPTURE=<出力先> swift test --filter StartSheetTests` でPNGへ撮り、モックと突き合わせる
