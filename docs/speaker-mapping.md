# 話者の手動統合

ウィンドウ上部の「話者…」から、検出された各話者の統合先を指定できる。同じ人物がAとCに分裂した場合、Cの統合先をAにする。「統合しない」を選ぶと元の判定へ戻る。

統合は直接指定で連鎖しない。A→B、B→Cの場合、元のAの発話はBへ、元のBの発話はCへ表示する。元の検出枠とトークンを保持するため、統合後も解除できる。

統合は検出枠全体に適用する。同じ枠に別人の発話が混ざった場合、発言ごとに分離することはできない。

録音中・一時停止中・停止後に変更できる。停止後は通常Markdownと省略前Markdownを再保存する。AIへ既に渡した範囲の話者を変更した場合は、次のコピーで訂正を通知する。話者名と統合先は、新しい録音を始めるとリセットする。

人数アイコンは最大4人分を並べ、統合先の重複を除いた人数だけ塗りつぶす。「使用枠」は、この会議でSortformerが一度でも検出した元の枠数を表す。暫定判定が消えても手動の統合先を確認・解除できるよう、検出済みの枠は残す。CをAへ統合しても、Sortformer内部のC枠は空かない。

声の追加照合による自動統合と人数上限設定は廃止した。古い設定ファイルに残った `maxSpeakers` は無視する。Sortformerによる話者判別は引き続き行う。

録音中の話者判定の固定猶予は30秒。後続の発話による修正を待つための試行値で、モデルの文脈長や推論遅延ではない。文字の表示は待たず、停止時は猶予や固定を外して全体を再判定する。猶予の延長だけで停止後の話者分裂が解消するとは限らない。

文字が確定済みでも話者判定の固定待ちが含まれる行は、薄い背景と「話者確認中」で表示する。固定後と停止後は通常表示へ戻る。文字自体が暫定の「聞き取り中…」とは区別し、「話者確認中」の行はコピーに含める。
