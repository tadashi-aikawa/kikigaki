# 話者の手動統合

ウィンドウ上部の「話者…」から、検出された各話者の統合先を指定できる。同じ人物がAとCに分裂した場合、Cの統合先をAにする。「統合しない」を選ぶと元の判定へ戻る。

統合は直接指定で連鎖しない。A→B、B→Cの場合、元のAの発話はBへ、元のBの発話はCへ表示する。元の検出枠とトークンを保持するため、統合後も解除できる。

統合は検出枠全体に適用する。同じ枠に別人の発話が混ざった場合、発言ごとに分離することはできない。

録音中・一時停止中・停止後に変更できる。停止後は通常Markdownと省略前Markdownを再保存する。AIへ既に渡した範囲の話者を変更した場合は、次のコピーで訂正を通知する。話者名と統合先は、新しい録音を始めるとリセットする。

人数ボタンは使用枠の数だけを出す。「使用枠」は、この会議で話者判別が一度でも検出した元の枠数を表す。手動の統合先を確認・解除できるよう、検出済みの枠は残す。CをAへ統合しても、話者判別の内部のC枠は空かない。上限の8はツールチップの「使用枠 3/8」で示し、旧版の4枠で録った会議も `/8` で表す。

声の追加照合による自動統合と人数上限設定は廃止した。古い設定ファイルに残った `maxSpeakers` は無視する。

E〜Hの枠はA〜Dの4色を順に使い回し、記号と名前で見分ける。

録音中の話者判定は、判定に読む入力が全て確定したフレーズから固定する。モデルの文脈長や推論遅延とは別の条件。文字の表示は待たず、停止時は固定を外して全体を再判定する。条件は `SpeakerFreeze.advanceByPhrase` を参照。

文字が確定済みでも話者固定待ちが含まれる行は、行全体を半透明で示す。行全体が固定された時と停止後の最終結果では通常表示になる。話者固定前もコピーに含める。

- 意味: 話者判別の判定待ちとアプリ側の固定条件待ちを含む。モデルによる再判定が常に動作していることを意味しない。
