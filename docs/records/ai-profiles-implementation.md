# AI設定の複数プロファイルの実装順の記録

2026-09-09から複数プロファイルを段階に分けて実装したときの実装順と、replayの追加入力の記録。現行の仕様ではない。現行は [AI設定の複数プロファイル](../ai-profiles.md) を参照する。

記録の中の `AIAgentResolver`、接続型の `connect`、稼働中ペインへの接続、準備済みセッションは、いずれも取り下げて撤去済み。実測の記録として残していた `attach = true` の検証記録は、取り下げた案の実測だったため削除した。

replayの追加入力は2つ。どちらも通常起動では解釈せず、`--smoke --replay` で形式だけ検証できる。

- `KIKIGAKI_DEBUG_AI_AUTO_SECONDS=<秒>`: 設定の `autoStart` の間隔を秒へ上書きする。分単位の設定値ではreplayの実行時間に収まらない
- `KIKIGAKI_DEBUG_AI_ASK_PROFILE=<name>`: 手動送信の宛先を固定する。自動と別のプロファイルへ同時に送ることを確かめる

各段のコミット前に `swift build` と `swift test` を通す。

## 採用した判断のレビュー

段1のレビューで決めた。段2はこの形で実装した。判断の内容は現行の文書の「採用した判断」にある。次の記述は現行の文書から外した。

- 切断したチャネルの「作り直す」について、段3で接続型に限って隠していた判定は、接続案の取り下げとともに外した。
- **ホットキーはプロファイルごとに持たない。** 宛先はシート内で選ぶ。プロファイル数だけ予約すると録音・一時停止との衝突検証が組み合わせで増える。グローバルショートカットはその後まとめて廃止した。
