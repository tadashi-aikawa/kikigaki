# 話者の割当と固定

トークンへ話者を割り当てる補正の順序と、録音中に話者を固定する条件をまとめる。文字列とトークン時刻は変更せず、設定追加はない。音声の話者区間を正解と断定したり、文字起こしの抜けを補完したりする機能ではない。

試験の経緯と比較の結果は記録に残してある。

- [話者補正の除外比較とフレーズ固定の試験](records/speaker-correction-trial.md)
- [被りの島の補正を段階的に強める試験](records/speaker-overlap-islands.md)
- [話者交代の語頭・語尾補正の測定記録](records/speaker-boundaries.md)

## 補正の順序

`Aligner.speakers(for:segments:frozen:)` が次の順に当てる。録音中・停止時とも同じ処理を使う。

1. 窓判定と長い語頭の補正: トークン中央±0.5秒の窓と区間の重なりを話者ごとに合計して最大を採る。同点は番号の小さい話者に倒す。続けて、長い1文字の語頭を後続の話者へ付け替える
2. 語内補正: 語内で割れた話者を文字数の過半数へ揃える。過半数が無い語に、語内の長い語頭の付け替えを当てる
3. 被りの島の補正: 話し手の声が重なった短い別話者の島を両隣の話者へ戻す
4. 句読点の付け替え: 句読点だけのトークンを直前のトークンの話者に付ける

- 凍結済みのラベルはどの段階でも書き換えない
- フレーズの多数派へ短い別話者の区間を吸収する補正は2026-09-26に廃止した。どの段階もフレーズの多数派を使わない

## 語内補正

1. フレーズ全文の日本語語境界と、ASRトークンの両端が一致する語だけを対象にする。1トークンに複数語が含まれる場合は分割しない
2. 全トークンが既知話者で、長さが正かつ有限、凍結済みを含まない語だけを対象にする
3. 文字・数字の数で、過半数を占める一意の話者へその語を揃える。同点を語末などへ決め打ちしない
4. 過半数が無い語のうち、次の「語内の長い語頭」の条件を満たすものだけ、語頭の1文字を付け替える

語頭のトークンには前の発話や無音が含まれて長くなることがあるため、語内に限って文字数を用いる。ただし文字数は音声の確信度ではなく、元判定の誤りも引き継ぐ。

### 語内の長い語頭

語の先頭が0.8秒を超える1文字で、その1文字だけが別の既知話者のとき、語頭を語の残りの話者へ付け替える。変えるのは語頭の1文字だけで、語の残りと語の外は変えない。次の全てを満たす場合に限る。

- 語頭と後続が同じ語である。語の条件は上の1と2と同じ
- 語頭は既知の話者。不明の語頭を新しく補わない
- 語の残りのトークンが全て同じ既知話者で、語頭の話者と違う
- 後続話者の区間が、語頭の末尾0.12秒以上を途切れず覆う。同じ話者の区間が隙間なく続けば、分かれていても覆うとみなす
- 文字数の過半数では決まらない。過半数がある語は従来どおり語全体をその話者へ揃え、この付け替えは行わない

原音で話者を確認した「思 / い通り行きます。」「自 / 己肯定ですよ。」は、どちらも全体が同じ話者だった。区間データでは、語頭の時間の前半に別話者の区間があり、後続話者の区間が語頭の末尾から切れずに続く。

- 推測: 前半は文字にならなかった別話者の声で、語頭の文字自体は末尾で発音された。原音で確かめたのは話者の正解だけで、この発音位置は区間データからの推測
- 下の「長い語頭と丁寧語尾」の補正は、語頭の前半が無音であることを根拠にする。前半に別話者の声があると働かない

独立した短い返答を奪わないため、同じ語の中だけを対象にする。「はい」「あ」のように、それ自体で1語になる返答は動かない。NLTokenizer が別人の1文字と後続の語を1語にまとめた場合は、誤って付け替え得る。

### 長い語頭と丁寧語尾

0.8秒を超える1文字だけを対象に、文字区間末尾の発話塊が0.5秒以上の間の後にあり、声が文字末尾の0.12秒以内まで届く場合を調べる。後続の文字が0.35秒以内に続き、その話者と末尾の発話塊の75%を超える話者が一致するときだけ語頭を補正する。末尾に当該話者の声が0.01秒以上あることも必要。複数文字を含むトークンや、重複発話で条件を満たさない箇所はこの補正では動かさない。

尾部の最初だけ他話者が重なる場合は、他話者の区間が終わった後、後続話者の単一区間が末尾まで0.12秒以上を覆う場合も補正する。無音だけの尾部を後続話者の声として数えない。

隣接する「ます」「です」は直前の語に接続して語内の文字数の集計に含める。句読点・空白を越えず、語尾終端がASRトークンの実質終端と一致する場合だけ適用する。混在トークンを途中で分割しない。

直前の語がすでに「ます」「です」で終わる場合は接続しない。「思います」「ですよね」を「思いますです」へ伸ばす誤接続を防ぐ。これだけで「ですよね」など複数語の短い返答を必ず保持できるわけではない。

## 被りの島の補正

話し手の発話に別話者の声が重なった区間で、話し手の本文の一部が別話者の行へ割れる。これを両隣の話者へ戻す。実装は `SpeakerIslands`。

有意文字のトークンを時刻順に並べ、同じ話者の連続を「島」と呼ぶ。島 R (話者X) を次の全てを満たすとき、両隣の話者Yへ戻す。

1. 島の直前と直後の有意文字がどちらも同じ既知話者Yで、Xも既知でYと違う
2. 島の長さ (最初の文字の開始〜最後の文字の終端) が1.5秒以下
3. 島の各有意文字に、Yの区間が `min(文字の長さ, 0.12秒)` 以上重なる
4. 両隣との間に0.35秒以上の間が無い。文末・結果境界をまたいでよい

- 判定は語内補正と長い語頭の付け替えの後、句読点の付け替えの前に置く。句読点だけのトークンは島に数えず、句読点の付け替えが直前の文字の話者へ揃える
- 不明 (区間なし) の島は補わない
- 条件3は、島の間も話し手の区間が続いていることを確かめる。話し手の区間が途切れた間の返答は戻さない

### 補正前のラベルで判定する

島の判定は、毎回補正前のラベルで行う。凍結済みの補正後ラベルを、次の島の隣の根拠にしない。

- 理由: 「0 1 0 1 0」の真ん中の0も短く1の声が重なると、一括では2つの1と真ん中の0がそれぞれ反転する。前半を補正後のラベルで凍結した後に真ん中を判定すると、隣が補正後の0になり一括と食い違う
- 実装: 凍結境界の手前も補正前のラベルを計算し直す
    - 範囲: 最初の未凍結トークンの1.5秒前より前に始まる最後の有意文字を含むフレーズの先頭から
    - 根拠: 境界に触れる島は1.5秒以内に始まり、その直前の文字を隣として読む。凍結済みの範囲は入力が確定しているので、計算し直しても凍結時と同じ補正前のラベルになる
    - 出力: 凍結済みのトークンは凍結したラベルのまま返す

### 凍結済みの行から始まる島

凍結済みの部分が既に戻っている場合だけ、後半も戻す。前半が戻っていない島の後半だけを戻すことはしない。

## 録音中のフレーズ凍結

録音中は、判定に読む入力が全て確定したフレーズを丸ごと凍結し、確定済みの行を後から塗り替えないようにする。実装は `SpeakerFreeze.advanceByPhrase`。凍結済みの末尾から始まるフレーズ P を、次の全てを満たすときに丸ごと凍結する。満たさなければそこで止め、後ろのフレーズも凍結しない。

1. P の全トークンが高精度側で確定済み
2. P の終端が確定している
    - 文末記号で終わるなら、それだけで確定
    - 0.35秒の間・結果境界で閉じる場合は、次のトークンも高精度側で確定済み
    - 理由: 速報側のトークンは `phraseId` が負で必ず結果境界になり、後で差し替わる
3. P 内の長い1文字の後の最初の有意文字が P の外にあれば、その文字も高精度側で確定済み
    - 後続の有意文字がまだ無ければ保留する
    - 理由: 長い1文字の語頭の付け替えが後続の割当を読む。語内の長い語頭の付け替えは同じ語、つまり同じフレーズの中だけを読むので、1で足りる
4. 判定済み末尾 `judgedUntil` が、読む区間の範囲以上
    - 範囲: P のトークンと3の依存文字の `max(終端, 中央+窓の半幅)`。窓の半幅は0.5秒
    - 根拠: `SpeakerRuns` は判定済み範囲の中身を後から変えない
5. 間の無い後続のフレーズも、P の終端から1.5秒を超えた有意文字を含むフレーズまで、1〜4を満たす
    - 理由: 島の補正は、フレーズの末尾の島を間の無い後続のトークンとその次の有意文字で判定する。その隣の話者は語内補正後の値で、隣のフレーズ全体に依存する
    - 間の有無は、次のフレーズの先頭トークンが高精度側で確定してから判定する
    - 後続のフレーズがまだ無ければ保留する。間のある境界では待たない

- 長い無音の直前のフレーズは、文末記号が無いと次の発話が高精度で確定するまで凍結しない。30秒での逃げ道は置かない
- 取消は保存しないので対象外。モデル失敗後は `judgedUntil` が止まり、条件4で凍結も止まる。一時停止中は入力が無く、凍結も進まない
- 固定待ちは、9/26 の等倍の記録で中央値が20.5秒、p90が28.7秒、最大が34.7秒。島の補正の採用前は15.4 / 22.6 / 27.7秒で、間のない境界で後続のフレーズを待つため中央値が約5〜8秒延びた
- 文字起こしの確定と話者判定の正しさは別であり、確定した文字列でも話者は誤ることがある

## 停止時の再判定

停止時は凍結を外して全体を再判定する。録音中に固定したフレーズと停止時の判定は、記録した10本の再生で不一致が0だった。

## 受け入れた限界

- 長い語頭以外の同点の語、複数語を含むASRトークン、語の外に残る短い別話者の断片、3話者の曖昧な境界は残り得る。すべての連続交代を正しく分離する保証はない。原音の人手評価は別途必要で、再処理結果だけから実際の話者を断定しない
- 話し手の区間が重なる中で、別話者が実際に言った「はい」「そうですね」も話し手へ戻す
    - 理由: 区間だけでは、文字にならなかった相槌と、文字になった返答を区別できない
    - 相槌の辞書で例外を作ることはしない
- 吸収の廃止で、吸収で直っていた実録の事例が元の形に戻る。テストは元の期待を `withKnownIssue` に残している
    - 不明の断片: 「欲 / しいなと」「で、/ 具体的には」の語頭が不明の行に残る
    - 文中の1語: 「代表」が相手の話者の行に残る
    - 語頭の分断: 「そ / うなんですよ。」の「そ」は0.54秒で、長い語頭に当たらない
    - 重なった文末: 別録音の「思い通り行きます。…」で、文末の「と思いますよ。」が重なった話者に残る
    - 島にならない語頭の分断: 「最 / 悪はもう。」「そ / うさせていただいて」
    - 話し手の区間が途切れた間の別話者の1文字は補わない。本当に別話者が発した可能性がある
- 文末記号の無いフレーズは次の発話の確定まで凍結を待つため、素材によって固定待ちのp90と最大は30秒猶予より長くなる
