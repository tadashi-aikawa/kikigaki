# アップデートの確認

メニューバーのメニューの「アップデートを確認…」で、GitHub Releases の最新のバージョンと手元のバージョンを比べる。JINRAI・KOKUKOKU・UTSUSHIE・KIKIGAKI で同じ仕様にそろえる。

- メニューの位置: 先頭の `KIKIGAKI <version>` の直下。その下に区切り線
- 走るのは押したときだけ。起動時・定期の確認はしない
- 確認中と、結果のアラートを出している間にもう一度押されても無視する。開発ビルドのアラートも含む
- 見る先: `GET https://api.github.com/repos/tadashi-aikawa/kikigaki/releases/latest`、ヘッダ `Accept: application/vnd.github+json`
    - 開発ビルドでは通信しない
- 現在のバージョンは `CFBundleShortVersionString`。`tag_name` の先頭の `v` を外し、SemVer の3要素で比べる
- 自前で .app を差し替えない。zip の asset は探さない。応答に `assets` が無くても読む
- 実装: 判定は `KikigakiCore/UpdateCheck.swift`、通信は `UpdateChecker.swift`、NSAlert は `UpdaterFeature.swift`
    - 型の分け方と名前は JINRAI にそろえる。取得処理は `UpdateCheckLogic.check(currentVersion:fetchLatestRelease:)` へ差し込む

## 結果の表示

すべて NSAlert で出す。スタイルは失敗だけ `.warning`、ほかは `.informational` を明示する。

| 場合 | タイトル | 本文 | ボタン |
|---|---|---|---|
| 現在のバージョンが SemVer として読めない | `開発ビルドです` | `開発ビルド(<現在のバージョン>)ではアップデート確認をスキップします。` | 既定のOK |
| 最新 | `最新版です` | `KIKIGAKI v<現在のバージョン> は最新です。` | 既定のOK |
| 新しいバージョンあり・Homebrew | `v<新しいバージョン> が利用可能です` | 下の「Homebrew の本文」 | `コマンドをコピーして終了` / `閉じる` |
| 新しいバージョンあり・Homebrew 以外 | `v<新しいバージョン> が利用可能です` | `現在のバージョン: <現在のバージョン>`、改行、`リリースページから新しいバージョンを入手できます。` | `リリースページを開く` / `閉じる` |
| 失敗 (警告スタイル) | `アップデートを確認できませんでした` | `<エラー文>`、空行、`リリースページで最新のバージョンを確認できます。` | `リリースページを開く` / `閉じる` |

- 現在のバージョン: 本文には SemVer として読んだ値の表記を出す。開発ビルドの本文だけは元の文字列をそのまま出す
- Homebrew の判定: `/opt/homebrew/Caskroom/kikigaki` か `/usr/local/Caskroom/kikigaki` があれば Homebrew
- Homebrew の本文: 案内の1文、空行、`brew update && brew upgrade --cask kikigaki && open -a KIKIGAKI`、空行、`コピーすると KIKIGAKI は終了します(更新完了後に自動で起動します)。`
- `コマンドをコピーして終了` はコマンドをクリップボードへ入れ、アプリを終了する
    - 理由: 起動中のプロセスは brew が .app を置き換えても古いまま動き続ける。コマンド末尾の `open -a` で新しいバージョンを起動させる
    - クリップボードへ書けなかったら終了せず、同じアラートをもう一度出す。`コマンドをコピー` も同じ
- `リリースページを開く`: 新しいバージョンありでは API の `html_url`、失敗では `https://github.com/tadashi-aikawa/kikigaki/releases`
- エラー文: API の失敗 (HTTP ステータス付き)、タグを解釈できない、通信エラー

## 録音中の例外

終了させない理由があるときに「新しいバージョンあり・Homebrew」になったら、アプリを終了させない。

- 理由: 進行中の録音・書き起こしと、保存できていない書き起こしを失わないため
- ボタン: `コマンドをコピー` / `閉じる`。コピーしても終了しない
- 判定: `KikigakiCore/UpdateCheck.swift` の `UpdateQuitBlocker.current`

| 理由 | 当たるとき | 本文の最後の行 |
|---|---|---|
| 進行中 | 準備中・録音中・一時停止中・保存中。待機中でも、音声ファイルの変換中・書き起こし中・仕上げ中 | `録音中のため KIKIGAKI は終了しません。録音を終えてから KIKIGAKI を終了し、コマンドを実行してください。` |
| 未保存 | 待機中で、停止時の保存に失敗した会議がメモリにだけ残っている | `保存できていない書き起こしがあるため KIKIGAKI は終了しません。保存してから KIKIGAKI を終了し、コマンドを実行してください。` |

- 音声ファイルの変換中: 開始シートで「開始」を押してから変換が終わるまで。状態は待機中のまま
- 未保存: 保存に失敗しても状態は待機中へ戻る。`MeetingSession.hasUnsavedMeeting`
- 待機中でないときは、未保存より進行中を出す。待機中の仕上げ中に未保存なら、未保存を出す
- 判定は2回行う
    - 確認の結果が出た時点で、表示を決める
    - `コマンドをコピーして終了` を押した時点でもう一度確かめ、理由があればコピーだけして終了しない。アラートを出している間に録音が始まることがある
        - 終了を止めたら、タイトル `KIKIGAKI は終了していません`、本文に上の表の止めた理由の1行、既定のOKだけのアラートを出す
