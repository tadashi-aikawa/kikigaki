# 話者交代の語頭・語尾補正

文字列とトークン時刻は変更せず、語内で割れた話者ラベルを補正する。録音中・停止時に適用し、設定追加はない。音声の話者区間を正解と断定したり、文字起こしの抜けを補完したりする機能ではない。

## 補正する条件

1. フレーズ全文の日本語語境界と、ASRトークンの両端が一致する語だけを対象にする。1トークンに複数語が含まれる場合は分割しない
2. 全トークンが既知話者で、長さが正かつ有限、凍結済みを含まない語だけを対象にする
3. 文字・数字の数で、過半数を占める一意の話者へその語を揃える。同点を語末などへ決め打ちしない
4. 過半数が無い語のうち、次の「語内の長い語頭」の条件を満たすものだけ、語頭の1文字を付け替える

フレーズの多数派へ短い別話者の区間を吸収する補正は2026-09-26に廃止した。語内補正はフレーズの多数派を使わない。経緯は [話者補正の除外比較とフレーズ固定の試験](speaker-correction-trial.md)。

## 語内の長い語頭

語の先頭が0.8秒を超える1文字で、その1文字だけが別の既知話者のとき、語頭を語の残りの話者へ付け替える。変えるのは語頭の1文字だけで、語の残りと語の外は変えない。次の全てを満たす場合に限る。

- 語頭と後続が同じ語である。語の条件は上の1と2と同じ
- 語頭は既知の話者。不明の語頭を新しく補わない
- 語の残りのトークンが全て同じ既知話者で、語頭の話者と違う
- 後続話者の区間が、語頭の末尾0.12秒以上を途切れず覆う。同じ話者の区間が隙間なく続けば、分かれていても覆うとみなす
- 文字数の過半数では決まらない。過半数がある語は従来どおり語全体をその話者へ揃え、この付け替えは行わない

原音で話者を確認した「思 / い通り行きます。」「自 / 己肯定ですよ。」は、どちらも全体が同じ話者だった。区間データでは、語頭の時間の前半に別話者の区間があり、後続話者の区間が語頭の末尾から切れずに続く。

- 推測: 前半は文字にならなかった別話者の声で、語頭の文字自体は末尾で発音された。原音で確かめたのは話者の正解だけで、この発音位置は区間データからの推測
- 下の「長い語頭」の補正は、語頭の前半が無音であることを根拠にする。前半に別話者の声があると働かない

独立した短い返答を奪わないため、同じ語の中だけを対象にする。「はい」「あ」のように、それ自体で1語になる返答は動かない。NLTokenizer が別人の1文字と後続の語を1語にまとめた場合は、誤って付け替え得る。

## 長い語頭と丁寧語尾

0.8秒を超える1文字だけを対象に、文字区間末尾の発話塊が0.5秒以上の間の後にあり、声が文字末尾の0.12秒以内まで届く場合を調べる。後続の文字が0.35秒以内に続き、その話者と末尾の発話塊の75%を超える話者が一致するときだけ語頭を補正する。末尾に当該話者の声が0.01秒以上あることも必要。複数文字を含むトークンや、重複発話で条件を満たさない箇所はこの補正では動かさない。

尾部の最初だけ他話者が重なる場合は、他話者の区間が終わった後、後続話者の単一区間が末尾まで0.12秒以上を覆う場合も補正する。無音だけの尾部を後続話者の声として数えない。

隣接する「ます」「です」は直前の語に接続して語内の文字多数決に含める。句読点・空白を越えず、語尾終端がASRトークンの実質終端と一致する場合だけ適用する。混在トークンを途中で分割しない。

直前の語がすでに「ます」「です」で終わる場合は接続しない。「思います」「ですよね」を「思いますです」へ伸ばす誤接続を防ぐ。これだけで「ですよね」など複数語の短い返答を必ず保持できるわけではない。

語頭のトークンには前の発話や無音が含まれて長くなることがあるため、語内に限って文字数を用いる。ただし文字数は音声の確信度ではなく、元判定の誤りも引き継ぐ。

凍結済みのラベルはどの段階でも書き換えない。

## 観測した例

`2026-09-05_1529.wav` では、窓判定の別話者区間が188.76〜190.20秒の「ゃあもう10分の1そ」だった。

- 「じゃあ」は3文字のうち2文字が別話者で、語頭の「じ」を取り戻せる
- 「そう」は文字数が同点なので、語内補正では動かさない。「そ」は0.54秒で長い語頭に当たらない
- 既知の退行: 旧来は吸収が末尾の部分語「そ」を多数派の「う」側へ戻していた。吸収の廃止で「そ / うなんですよ。」の分断が残る。テストは元の期待を `withKnownIssue` に残す

音声側の区間はBが188.800〜190.080秒、Aが190.000〜190.800秒で一部重なっていた。「そ」のトークンは189.66〜190.20秒まで伸びており、音声区間へ最寄りで寄せるだけでは文字境界を決めにくい。この観測を踏まえ、音声時刻だけの補正は採っていない。

## 残る限界

長い語頭以外の同点の語、複数語を含むASRトークン、語の外に残る短い別話者の断片、3話者の曖昧な境界は残り得る。すべての連続交代を正しく分離する保証はない。原音の人手評価は別途必要で、再処理結果だけから実際の話者を断定しない。

## 全文再処理の結果

吸収の廃止前に測った結果。

- `2026-09-05_1529.wav`: 「じゃあもう10分の1」と「そうなんですよ。」の分離、74秒付近の「…とそ／うそう…」の語頭分断が変化した。「はい」「すごいね。」の保護は維持した
- `2026-09-05_1412.wav`: 同じ「…とそ／うるそう…」の境界と、93秒付近の「積み重ね」が変化した。「積み重ね」は4文字中3文字の別話者判定を保持する結果であり、実際の話者を確定した意味ではない
- 両方とも、省略後の発話本文を順に連結すると変更前と一致した。前回の74.58〜75.06秒「うんうん」1件の省略も維持した

## テスト

ユニットテストでは、実録境界に加え、同点、不明話者、凍結、第三話者、混在ASRトークンを検証する。長い語頭の付け替えは、2例の実録区間に加えて次の反例を検証する。

- 後続話者の区間が末尾を覆わない、または語頭の終端より後から始まる
- 語頭が不明、0.8秒以下、語の途中の長い1文字
- 語の残りが割れる、または不明を含む
- 独立した1語の返答
- 無音の後の語頭。既存の尾部補正で同じ結果になる
- 別話者の声が語頭の終端まで重なる
- 凍結済みの語頭、フレーズ固定の後の再判定
