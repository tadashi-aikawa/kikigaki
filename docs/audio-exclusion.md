# 小音量発話の除外

## 操作と判定

話者ポップアップに小音量発話の除外スイッチと−80〜−20 dBFSのスライダーを置く。初回はOFF、ON時の初期しきい値は−45 dBFS。選択は次回も記憶する。距離ではなく入力音量を判定するため、マイクや入力ゲインを変えたら再調整が要る。環境差が大きいため初回から自動で除外しない。OFFのあいだはスライダーとしきい値を畳み、説明文は置かない。録音開始シートでもON/OFFだけを切り替えられる。

操作から150 msのデバウンスで会議全体を再判定する。操作中の数値は即時更新し、定期的な画面更新で操作値を巻き戻さない。閉じる際は保留値を確定する。録音準備・終了処理中は操作不可。

停止直前の保留値は終了処理後に反映する。新しい会議へは持ち越さない。確定窓に収まった発話区間の音量はキャッシュし、設定変更では比較だけを行う。未到着区間は音声が揃ってから計算する。相槌省略のraw.mdには小音量除外を適用せず、全発話を元の順番で残す。

既存の100 ms RMSトラックから各行のP90を計算し、しきい値未満だけを除外する。相対基準は併用しない。欠測と手入力は残す。計測表示のON/OFFによらず新規録音は音量トラックを収集する。旧会議の欠測を後付けで除外しない。

## 表示・保存・送信

画面は全行を保持し、除外行を半透明で示し「小音量のため除外」と注釈する。スイッチOFFやしきい値の引き下げで元の発話を復元できる。数値の診断表示はmeasureAudioLevelsだけで切り替える。計測表は候補判定と適用設定を分け、「未除外」は使わない。

元の発話と音量トラック、会議ごとの適用設定をarchiveに保持する。通常Markdownの本文から除外し、末尾の「小音量で除外した発話」へ理由付きで全文を残す。停止後の再調整で再保存する。相槌省略とは独立させ、その原文も保持する。過去会議は保存された設定で描画し、現在の既定値で再判定しない。

コピー、AI範囲プレビュー、変更検知、手動・自動送信、音声からの質問と暫定末尾に同じ判定を適用する。AI操作開始時に設定を固定し、確定待ち中のスライダー変更を混ぜない。送信済みの文章を撤回する機能ではなく、次の送信で従来の差分訂正を通知する。復元も差分訂正になる。画面の全行と送信対象行のインデックスを混同しない。

「直前のコピー」は既存の不変スナップショットを再利用するため、除外設定を変えたら利用不可にする。差分の前回基準は保持し、通常のコピーで削除・復元の訂正を出せるようにする。音声質問の末尾が除外された場合に、それより古い声へ勝手に遡って質問しない。送信本文の末尾が残っていても、元の最後の声が除外対象なら音声質問は空として扱う。

## 実装上の契約

- 次回設定はUserDefaults、会議設定はMeetingのoptionalなaudioExclusionへ保持する。欠損はOFF。診断表示はoptionalなshowAudioLevelsへ保持し、旧会議はtrackの有無を旧設定として扱う。
- トラックは常時収集しarchiveへ保存する。独立のlevels.jsonとMarkdown計測表は診断ONの会議のみ生成する。AudioLevelReportは除外設定をoptionalで追加しschemaVersionを2とする。
- AICaptureへ固定した設定と最新のトラックを渡す。暫定末尾は全体区間のP90で判定し、欠測は残す。確定後の境界変更による訂正は許容する。除外により質問が空になった場合は専用の警告で送信を止め、問いの入力か除外設定の調整を案内する。
- コピーへは除外済み配列を渡し、start位置も同じ配列から作る。初回の空会話はコピーなし。以前の送信から全削除になった場合は削除訂正を送る。手動AIの明示質問は空会話でも送信できる。

## 検証

境界値、手入力、欠測、ON/OFF、再調整による復元、旧archive、保存再読込、診断OFFでの除外、コピー・AI本文・質問・暫定末尾の除外、除外後の空会話と復元訂正を検証する。ポップアップの操作値保持とデバウンスを確認し、全体テストと署名済みアプリのビルドを行う。
